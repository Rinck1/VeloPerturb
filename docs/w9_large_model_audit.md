## 审核后的模型定位

是当前短时群体端点分布模型的容量版，不是恢复9月的GFG/JVP、EM/ODE整套。K统一为8，PCA50、邻域解析动力学和群体均值底座冻结。大版**18,516,952个全部可训练参数**；小版76,248。旧18.5M部署计数包含大量冻结回退副本，与新大版的可训练参数不是同一口径。

大版共享残差骨干宽1216、6块，专家瓶颈64，router宽256。残差缩放1/√(2L)，专家末层微小非零初始化，避免完全对称或断梯度。

## 两个主要修正

1. **中心化一致性。** 旧训练在随机batch内扣q加权均值，推理在全源群体扣均值。W9训练与推理都使用完整源群体，并保留中心化项对参数的梯度。只有能量项的源/目标索引各采64个。
2. **有限batch目标。** 旧训练V-statistic有有限batch偏差。W9用独立源抽样的U-statistic：排除同一次源抽样的全部专家配对，而不只是flatten候选矩阵主对角。完整源中心化固定以后，训练估计对应经验群体能量的无偏抽样目标；负的mini-batch估计正常，不截断。

这两项是新目标与计算方式的修正，不能拿新大版直接对旧小版归因容量。因此小/大模型都按新目标、同学习率1e−4及同采样预算重跑，各自static/velocity配对。

## 数学不变量及主张边界

`y_ik = z_i + h(Δ) · (g + r_ik − μθ)`，`μθ = mean_i Σ_k q_ik r_ik`。

由Σ_k q_ik=1，完整预测均值严格等于源均值+h(Δ)g。测试同时检查数值恒等式和它对全部参数的导数为零，避免“值对但梯度detach错误”。

- 训练/评价均是候选混合，不把专家均值端点误当作生成分布。
- 原始解析U−γS未标定真实小时速率，只作为router的动力学上下文；专家率经状态尺度/24小时标定，h(24)=24。不是RNA速度的物理ODE积分。
- 专家原始输出S-only；velocity只进入局部router及其均值约束的间接路径。两臂共享的冻结群体均值读出仍用解析动力学，因此static指局部router的S-only，不是整条系统完全不读U。
- 推理必须把完整源群体作为一个population；不得把细胞拆成独立小batch、各自重新扣均值。
- 不识别逐细胞真实命运，不将K8解释为8个生物分支。全部r4结果仍是同系列开发评价。
