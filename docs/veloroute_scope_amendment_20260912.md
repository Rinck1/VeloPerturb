# 2026-09-12 用户授权调整：允许先构建 router/专家网络

用户明确说明“核心框架”指 router/专家网络，并回复“修改约束”。

本修订覆盖 v1.1 中“G1 前禁止编写模型代码”的规定。现在允许：

- 实现最小 router、共享骨干场、低秩专家头、责任度损失和模式锁定 ODE。
- 在合成数据上进行前向、梯度、训练、生成、保存与恢复的工程验收。
- 与数据预处理和诊断基础设施同时推进。

未修改的边界：

- 真实 RENGE 的正式模型实验仍须先完成 S/U、条件标签、切分、冻结预注册及 G1 判决。
- 合成数据的已知模式/配对只用于工程测试，不能作为真实未配对问题的命运标签，也不能冒充 G1-GO。
- velocity 始终为主线；本版明确是推理时读取源侧 velocity 的 router，不再称作“只用作训练监督”。
- 不以工程测试通过宣称真实 velocity 增量、router 独立贡献或论文成功。

首版不包含 GFG 预训练适配、可训练状态编码、内源速度场、复杂 EM、可靠度门控或自适应 K；这些不是今天核心网络能运行的前提。
