## 1. 本次调整的边界

velocity 始终是主线，不降为可选增强。router 是首选作用机制，但“velocity 有价值”和“router 是有效利用方式”分两道判决验证。

调整后的顺序为：

```text
资产与任务定义
  → RENGE 数据落地、预注册冻结
  → early-response 的 velocity 增量诊断（G1）
  → 最小路由模型与作用位置比较（G2）
  → 较长跨度预测及独立中间边际验证
  → de novo 独立验证（G3）
  → 正向复现、负对照、完整实验与写作
```

提高稳定性的方式是先验证较接近观测动态的任务、减少同时训练的模块、为每种阴性结果规定动作。不得在 velocity 无有效证据时，将静态 router 的阳性结果包装成动力学方法成功。

## 2. 任务定义与主张边界

### 2.1 三个任务分开报告

| 任务 | 测试输入 | 预测目标 | 本版定位 |
| --- | --- | --- | --- |
| ER-short | 已受扰动的 day4 源细胞 S/U，以及扰动 c | 同一条件 day5 群体分布 | 第一轮机制验证；优先检验短时间跨度上的 velocity 增量 |
| ER-long | 已受扰动的 day3 源细胞 S/U，以及扰动 c | 同一条件 day5；day4 可作独立中间验证 | G1/G2 后检验跨度增加时的收益和失效边界 |
| de novo | 对照 day2 源细胞 S/U，以及待预测扰动 c | KO day5 群体分布 | 保留原目标，但须独立过 G3，不能由 early-response 成功代替 |

ER-short 的优势只是待检验假设：源细胞的 velocity 已在扰动后的系统内测得，可能更接近接下来的变化。不得在结果产生前写成已证事实。

RENGE 的 day2 已是转导后第二天。对照 day2 → KO day5 是跨条件预测，不能自动解释成“从 day2 才开始施加扰动的三天真实演化”。同一 KO 相邻时间转移的训练，也不能自动覆盖对照源分布到 KO 的转换。

de novo 阶段须在训练条件上明确纳入对应的对照源 → KO 目标任务，或明确定义并验证干预切换机制。源细胞定义、干预时刻和时间编码须在该阶段正式测试前冻结。

### 2.2 三层证据不可混用

1. 分布证据：准确预测未参与拟合的终态或中间边际。
2. 动力学证据：真实 velocity 优于静态表达及合理置换对照。
3. 逐细胞命运证据：有独立谱系、克隆或其他源—未来联系支持归属。

当前数据首先承担前两层。Γ 标签、专家索引和模型产生的伪配对，不作为第三层的真值。没有独立命运联系时，“router 选择了有预测价值的响应分量”是可检验的表述，“恢复了每颗细胞的真实命运”不是已成立的结论。

### 2.3 时间验证的命名

- 训练覆盖 [2,5] 后测试 2→5，称为长跨度或组合预测，不称为超出时间支持范围的外推。
- ER-long 的测试条件 day4 若作为独立验证，其目标细胞不得进入拟合、参考场、组分发现、超参选择或早停。
- 在训练条件上做留出时间点验证时，被留出的时间点也必须从该协议的所有拟合环节中移除。
- OT 已约束过的终态边际不能再次作为“耦合正确”的独立证据。

## 3. 执行前必须遵守的约束

### 3.1 测试输入与拟合权限

- 测试输入以任务表为准，只允许该任务的源侧 S/U、已知条件 c 和预先定义的时间信息。
- early-response 允许已受扰动的源细胞；禁止的是未来目标数据及其他未授权目标信息，而不是所有受扰动细胞。
- 测试条件的未来表达、S/U、velocity、标签、细胞比例和其他统计，不进入预测输入或门控。
- HVG、数据驱动的归一化参数、PCA、速度估计器、邻居参考库和模式发现只在训练折拟合；超参和早停只用开发侧验证条件，不使用最终测试条件。
- 源侧测试细胞只能通过冻结变换，不能与未来目标一起重新拟合 velocity 或构造邻居图。
- 外层按扰动基因切分，同一 TF 的两个 gRNA 不得跨训练与测试；验证条件与最终测试条件分开。
- G1/G2 的路线选择、组件开发和预算调整只使用开发侧留出条件。最终确认测试条件及其各时间点从一开始封存；不能反复查看同一测试集，再用它证明新版本的泛化。
- 若不同任务复用最终测试 TF，必须在查看这些 TF 的 early-response 结果前，冻结拟报告的 ER-long/de novo 方法和预测。否则后续结果只能标为探索性，或使用新的独立确认数据。
- 测试预测文件和 provenance 冻结后再评估。测试结果不得反过来修改本轮阈值或模型。

### 3.2 velocity 与模型的作用位置

最小模型采用“源侧动力学条件化路由”：部署 router 可读取冻结变换产生的源侧 velocity 或其表示；专家负责表达分布的演化。

- c 不直接输入动力学编码器。该计算图约束不代表动力学表示与 c 统计独立。
- velocity 主要影响候选耦合或响应模式的选择，不作为最小模型的表达回归目标，也不直接叠加到预测向量场。
- 若 router 在推理时依赖 U/velocity，文稿不得称其为“只作训练监督”。
- 仅训练期使用 velocity 的特权监督版本可作为后续消融，但必须单列；不能期待 S-only 学生恢复只存在于 U 的逐细胞差异。

### 3.3 诊断前允许与禁止的工作

允许：数据处理、训练折内拟合已有 velocity 估计器、调用已审计的预训练件、运行固定预算的简单诊断探针，以及验证诊断实现的合成实验。

最新修订：用户已允许 G1 前实现及探索性训练完整 VeloRoute；必须使用显式 exploratory 入口并与正式结果分开。仍禁止自由架构搜索、反复调参寻找阳性，不能由探索性训练完成自动推出 G1-GO。

固定低成本探针属于判决实验，不等于提前进入完整模型阶段。其结构、预算、选择规则和切分必须先记录，再运行。

## 4. Phase 0：资产、数据与预注册准备

建议预算：第 1 周。原始数据获取速度或硬件限制导致延期时，记录实际阻塞，不跳过退出条件。

### 步骤 0.1：确认现有资产

1. 找到实际服务器仓库、运行环境、数据目录、CellFlow checkpoints 和实验配置。
2. 阅读并核验前期阴性报告，记录每个关键数字的实验路径、数据版本、指标定义和切分。
3. 补跑已有 diagnostics 模块和相关测试，确认此前“已写未测”的代码状态。
4. 审计 GFG/VeloVI 的输入空间、预处理、冻结方式和预训练数据来源；不能假定任意 checkpoint 能直接接受 PCA-100。
5. 核验存储、下载和计算资源。预训练资源不齐时使用已预注册的简单估计器/编码器，不临时扩大方法规模。

历史报告不能推出“velocity 信息包含于 ESM”等信息论结论。kNN 探针结果也不能直接称为信息上限。

产出：`outputs/veloroute_phase0/ASSETS.md`、环境记录、测试结果、历史证据索引。

### 步骤 0.2：重建 RENGE accession 清单

GEO 的 8 个样本是四个时间点的 mRNA 与 gRNA 两类文库：

| 时间点 | mRNA 文库 | gRNA 文库 |
| --- | --- | --- |
| day2 | GSM6571143 | GSM6571144 |
| day3 | GSM6571145 | GSM6571146 |
| day4 | GSM6571147 | GSM6571148 |
| day5 | GSM6571149 | GSM6571150 |

- 按 accession 明确每个 run 的文库类型和所属样本，不按文件大小猜测 GEX。
- SRR21518311 属于 day3 mRNA；同一实验还有 SRR21518312。必须核验完整 run 清单，不能把一条 run 当作全部样本深度。
- 同一文库的多次测序不能当作独立生物重复，应按已验证的 barcode/UMI 规则合并处理。
- gRNA 文库承担条件标签识别，不得混作低深度 GEX。
- 清单至少记录：GEO/SRA accession、day、library_type、生物样本、run、文件校验和、read 布局和处理状态。

### 步骤 0.3：先单时间点试处理，再扩展四天

1. 用完整的一个时间点验证 technical reads、barcode/UMI 布局、白名单匹配和 gRNA 对齐。
2. 再运行 NCBI 提取 → simpleaf USA 定量 → 基因标识对齐 → 细胞/条件元数据整合。
3. 对每个样本分别检查空滴、双细胞、gRNA 多重分配、测序深度和 S/U 覆盖。
4. 保留 gRNA 级质量信息；按基因合并前先检查同一 TF 两条 gRNA 的响应一致性。
5. 按样本命名空间保存 barcode，防止不同时间点的同名 barcode 被误配。
6. 确定外层和内层切分后，才进行各折的数据驱动特征选择、PCA 和速度拟合。

4.66% 内含子 reads 等既有审计数字只作为处理可行性的线索，需在实际使用的完整数据上复核；不能直接作为 velocity 有效性的判据。

5045 个 ENSG 不作为所有新数据集的强制基因集合。RENGE 的基因选择由训练折确定，同一实验内所有方法使用公平一致的评估空间。

产出：`run_manifest.csv`、`cell_manifest.csv`、`data_qc.csv`、`split_manifest.csv` 和处理日志，统一置于 `outputs/veloroute_phase0/`。

### 步骤 0.4：冻结正式诊断协议

正式结果产生前，记录并版本化：

- 主任务 ER-short；ER-long 和 de novo 的后续验证定位。
- 外层条件切分、内层验证切分、至少 3 个固定 seeds。
- 速度估计方法、冻结方式、预训练资源，以及每个对照臂允许读取的特征。
- 固定探针、训练预算、早停规则和各臂容量匹配方法。
- 一个预指定的主分布指标；建议使用固定 PCA 空间的 energy distance。扰动特异指标和结构指标另行明确名称与实现版本，不以“官方 15 指标中最好的一个”作判决。
- 置换分层、条件化方法、置换次数、置信区间方法及缺失/小样本条件的处理规则。
- 最小可检测效应、实际有用增益和后续非劣效容忍幅度的设定依据。可用独立重复、历史验证噪声或合成功效分析确定，不能依据本轮效果调整。
- GO、停止和证据不足的判据，以及每种结果对应的下一步。

本执行文档不等于已经完成实验预注册。只有清单、指标实现和上述参数填写完毕并产生版本哈希后，正式诊断协议才算冻结。

退出条件：完整数据清单、可复现 S/U 与 gRNA 对齐、可用切分、通过的诊断实现检查、已冻结的诊断协议。

## 5. Phase 1：early-response 的 velocity 判决 G1

建议预算：第 2–3 周。该阶段的目标是判断 velocity 是否有独立预测增量，不要求先证明 router 有效。

### 步骤 1.1：动力学可用性审计

检查细胞级 UMI 和 U 覆盖、有效动力学基因、相图支持、不确定度、下采样/处理扰动下的稳定性，以及独立时间变化的支持程度。

须区分三个量：对参考估计器的拟合误差、估计器自身的不确定度、对未来响应的预测价值。它们不能相互代替。

### 步骤 1.2：异质响应结构审计

- 在训练数据上检查可复现的组分、连续异质性与多峰性。
- 检查细胞类型、编辑逃逸、gRNA、批次、应激、增殖和存活的解释作用。
- 使用预注册的单峰性检验及功效分析；Sarle 系数和二均值分离仅作辅助描述。
- 不只沿 pseudobulk 效应方向检查，避免漏掉均值抵消的异质响应。
- 没有独立谱系证据时，不将多峰直接解释成分岔。

多峰比例不再作为 velocity 主线的唯一开关。没有明显多峰，但存在可验证的时间分布增量时，仍可继续 velocity 单场路线；router 是否值得进入由 G2 单独判断。

### 步骤 1.3：任务增量四臂 A

所有臂保留相同条件 c、时间信息、表达预处理和预算：

| 对照臂 | 源侧信息 | 目的 |
| --- | --- | --- |
| A0 | S | 静态表达基线 |
| A1 | S + 真实 velocity | 动力学任务增量 |
| A2 | S + 合理置换的 velocity | 检查增益是否依赖正确的源侧对应 |
| A3 | velocity；仍保留 c 和时间 | 辅助判断动力学信号的独立预测能力 |

使用固定、低成本的分布预测探针。其失败可用于本轮资源止损，但不得写成“所有可能的 velocity 路由方法均不可能成功”。

### 步骤 1.4：信息来源四臂 B

| 对照臂 | 源侧信息 | 目的 |
| --- | --- | --- |
| B0 | S | 表达基线 |
| B1 | S + 真实 U | 检查 U 的增量 |
| B2 | S + 由 S 预测的 U | 检查真实 U 是否超出表达可预测部分 |
| B3 | S + 条件化置换的 U/残差 U | 减少不真实 S/U 配对造成的伪增益 |

- 预测 U 的模型只在训练折拟合，训练内需要评估时使用交叉拟合。
- 对照考虑 donor、样本、时间、细胞类型、测序深度和相近 S 状态；缺失的分层变量不能凭空填造。
- 不能把不同时间点的 U 混洗，也不能把测序技术重复当成独立样本。
- 控制额外分子计数/测量质量带来的收益。B1 阳性本身不能单独证明动力学机制。
- 检查所有使用 velocity 的消费者：置换臂不能通过未置换的参考场、标签或其他支路读取真实动力学信息。

### 步骤 1.5：独立时间锚与合成检查

运行真实/置换 velocity 的耦合比较。若需要时间锚，使用未参与耦合构造和选择的时间点；不得用已强制匹配的目标边际给耦合打分。

保留四类合成系统：无增量、路径有增量、位置决定模式、动力学决定模式。诊断阶段检查统计流程是否区分这些系统；完整 router 的训练与模式恢复测试在 G1 后进行。

特别加入“相同 S、不同 velocity”的系统，检查参考场平均是否抹掉预期信息。合成真实标签只在允许的训练/评估角色使用，不能输入真实数据任务。

### G1 判决

统计比较以条件为主要单位；同一条件的多个 seeds 不能当作额外独立生物重复。默认采用条件级配对 bootstrap 95% 置信区间，以“对照误差减真实 velocity 臂误差”为正向收益；主比较下界大于 0，且满足预注册实际收益要求，才判为增益成立。bootstrap 细节和多重比较处理在 Phase 0 冻结，至少报告方向、幅度和功效。G1 的判决来自开发侧留出条件，不打开最终确认测试集。

| 结果 | 下一步 | 可报告的结论 |
| --- | --- | --- |
| A1 对 A0/A2 的主指标增益可信，达到预注册实际收益要求，B 支持 U 的增量，且结构/扰动特异证据不与主张冲突 | G1-GO，进入最小 router | 当前任务上 velocity 存在可利用的预测信息 |
| U 有增量，但当前 velocity 估计没有增量 | 不进入完整 router；检查已预注册的估计器替代方案 | 当前证据支持 U 信息，不足以支持 velocity 主张 |
| 真实 velocity 不优于合理对照，且功效足够 | 停止该数据/任务上的路线；仅允许一次预先指定的替代数据验证 | 该协议下未发现有用的 velocity 增量 |
| 置信区间宽、样本量不足或处理质量不过关 | 标记证据不足；按预定预算补数据/修复处理，超预算停止 | 不作“无效”或“有效”的科学结论 |

Phase 1 结束形成判决报告并向项目负责人/导师汇报。新的数据获取或其他外部协调按现有授权执行，不自动发送邮件或消息。

产出：`outputs/veloroute_g1/RESULTS.md`、`metrics.csv`、置信区间表、四臂结果、审计图、provenance 和明确的 G1 判决。

## 6. Phase 2：最小模型与 router 判决 G2

仅 G1-GO 后进入。建议预算：第 4–6 周。

### 步骤 2.1：建立最小表达专家与比较口径

- 固定 PCA-50 状态和逆 PCA；首版不另学一个不受约束的非线性状态坐标。
- 优先复用已验证的表达 flow 骨干与条件表示。
- 使用少量专家，先做 K=1 与 K=2；是否扩展到 K=4 只由训练/验证证据和预注册预算决定。
- 先让表达专家形成可区分候选，再研究 velocity 的选择作用。必要时用训练折表达结构播种，但标签只代表统计分量。
- 专家上下投影不能同时零初始化；可下投影随机、上投影零初始化。
- 不在首版叠加内源速度场、不使用复杂延迟老师、不引入自适应 K 或逐求解器调用加噪。

### 步骤 2.2：明确 velocity 如何区分候选响应

原代价中的动力学项若只有 D(i,j)，则在给定细胞对的 k-softmax 中抵消，只能通过改变 Γ 间接改变模式归属。不能将它解释成对候选模式的直接动力学打分。

进入正式训练前，补充方法规格，明确以下两种作用位置中的实际实现：

1. velocity 改变细胞配对，router 学习其聚合责任度；
2. velocity 对不同候选模式的源侧局部行为产生不同兼容性分数，直接影响模式选择。

两者需要分别消融。优先保留逐源细胞的动力学信息，不只使用按 S 平均的参考场。任何模式兼容分数都不是独立命运标签，仍须用外部预测结果验证。

冻结表达候选进行初始路由实验，减少专家、路由标签和参考量同步变化带来的循环性。联合更新只在该实验成立后引入。

### 步骤 2.3：四个主模型及必要负对照

| 模型 | 表达结构 | velocity 作用 | 核心比较 |
| --- | --- | --- | --- |
| M0 | 静态单场 | 不使用 | 基础表现 |
| M1 | 静态 router + 多专家 | 不使用 | 多专家/路由本身的增益 |
| M2 | 单场 | 辅助耦合 | velocity 是否改善运输学习 |
| M3 | router + 多专家 | 动力学耦合/模式选择，按实际规格区分 | router 是否进一步利用 velocity |

M2/M3 都要有相应置换对照。预算、可训练参数、表达编码和预训练资源需公平匹配；GFG 不能成为 full 模型独享的未控制优势。

附加路由对照：固定混合比例、仅条件路由、源细胞状态路由。冻结专家后可干预路由权重，检查收益是否确实依赖所声称的分配信息。此类干预只解释预测功能，不证明真实命运。

### 步骤 2.4：保持训练、推理和梯度一致

- 生成时按 router 采样一次模式并锁定；训练采用对应的逐专家责任度加权损失或采样方式，不能仅回归专家平均场后直接换成单专家生成。
- 明确回归的是完整场还是残差场。首版没有额外内源场，不重复记账。
- 明确每项损失的 detach 边界，检查实际梯度；独立优化器组不等于梯度隔离。
- 物理时间、归一化时间和速度估计器的量纲需要一致定义。velocity 与表达速率作比较时，只使用训练期固定的坐标/尺度变换。
- 不把专家使用率自动称作命运比例，不强制每个条件均匀使用所有专家。
- 在合成系统中检查路由、专家初始化、模式坍缩和“相同 S、不同 velocity”的区分能力，再进入正式真实数据实验。

### G2 判决

- M3 相对 M1 的增益：检验 velocity 是否有贡献。
- M3 相对 M2 的增益：检验 router 是否比 velocity 单场进一步受益。
- M3 相对其置换版本的增益：检验正确动力学对应是否必要。
- 判决采用预注册指标、条件级区间和多 seed 结果；不能仅依据路由熵、Γ 一致率或挑选出的单个条件。

| 结果 | 下一步 |
| --- | --- |
| M3 同时支持上述比较，且独立结构/分布指标符合预注册主张 | G2-GO，保留 velocity-router 核心方法 |
| M2 有效，M3 没有额外收益 | 保留 velocity 主线，转向动力学辅助运输；撤回 router 独立贡献主张，补做相对已有方法的创新性审查 |
| M1 有效，但 M2/M3 的真实 velocity 不优于对照 | 不将静态路由结果视为本项目成功；停止或回到预先限定的数据/估计器检查 |
| 结果不稳定或专家尚未形成有效候选 | 记录瓶颈；只在预注册预算内修复，不无限扩展架构 |

产出：`outputs/veloroute_g2/RESULTS.md`、模型比较 CSV、路由消融、参数/预算统计、合成检查、provenance 和 G2 判决。

## 7. Phase 3：扩大时间跨度，再独立验证 de novo

建议预算：第 7–9 周。允许根据前两道判决收缩范围。

### 步骤 3.1：ER-long 与中间边际

先从 ER-short 扩展到 day3 → day5，检验 velocity 增益随跨度的变化。对测试条件的 day4 进行独立边际评估，并记录其未参与拟合和选择的证据。

短跨度成功、长跨度失败，应报告有效时间范围；不得用 day4 → day5 的成绩替代 day3 → day5。

### 步骤 3.2：de novo 协议补齐并冻结

1. 明确对照 day2 与 KO day5 的任务语义及训练样本构造。
2. 明确是否结合训练条件的相邻时间转移，避免把不同任务混为一组训练成绩。
3. 对所有基线提供同等条件和时间信息，不让时间信息成为 full 的额外优势。
4. 冻结五折按 TF 的条件泛化协议；leave-one-TF-out 可作为预算允许下的扩展，不能依据测试表现选协议。
5. 再次审计测试条件的 KO 数据是否曾进入预训练、参考场、模式发现或选择环节。

### G3 判决

- de novo 的真实 velocity-router 必须在该任务上独立优于相应静态和置换对照，才可提出 de novo 动力学预测主张。
- early-response 成功而 de novo 失败：论文限定为早期响应条件下的后续分布预测，诚实报告边界；不自动宣布整个 velocity 主线失败。
- 如果按 G2 已转为 velocity 单场，则对该方法执行对应的 G3 比较，不保留未经支持的 router 主张。

产出：`outputs/veloroute_temporal/` 和 `outputs/veloroute_denovo/` 中分别保存结果、预测和审计记录，任务间不得混报。

## 8. Phase 4：复现、负对照与论文产出

建议预算：第 10–14 周；已有可信结果时可提前开始写方法与协议部分。

### 步骤 4.1：数据扩展按证据价值排序

1. RENGE 是时间×遗传扰动主数据。
2. Kang 是候选正向验证，先审计 velocity 和源任务；不预设 IFN 响应一定双峰。
3. PerturbSci-Kinetics 可验证第二模态信息，但 nascent/whole 与标准 S/U 分开定义，不能自动算 velocity 方法的直接复现。
4. Norman 用于静态数据上的收益边界和非劣效检查；本项目所用版本的条件数与切分须由清单确认。Norman 的干预是 CRISPRa，不是 CRISPRn。
5. Replogle 在 provenance 与计算资源允许时扩展负对照。
6. hPSC 大规模屏在前述结果成立后再考虑，不进入首轮关键路径。

### 步骤 4.2：按贡献逐个增加组件

原建议为逐个增加组件。用户后续明确要求全量实现，现已在探索性版本中同时接通除 GFG 初始化外的上述组件；这不替代逐项贡献消融。后续保留固定预算，按真实增量证据决定是否扩大实验。

若增加门控：

- 标签必须明确；若 g 表示开启动态分支，则破坏标签不能直接以 1 监督 g。
- corruption 检测不等于预测任务收益。
- 若主张“关闭时恢复静态基线”，必须保留能真正恢复的静态预测器；受动态训练影响的共享骨干不提供此保证。
- 全体条件不劣必须用预注册非劣效幅度和区间检验，不能用“不显著”代替。
- 未得到独立约束的内源/扰动场分解只能作为模型记账，不作唯一的生物学归因。

### 步骤 4.3：最终确认、相关工作与论文主张

先完成开发侧模型选择，冻结方法、各任务预测、指标和分层，再评估从 Phase 0 封存的最终确认条件。按外层五折报告时，每一折的方法选择不得读取该折测试结果；正式确认后不得按结果继续调整同一轮模型。

至少比较并讨论 CellFlow、scDFM、Curly-FM、FLUX 和与实际任务匹配的分布预测方法。FLUX 已涉及未配对时间序列的专家场和路由，普通 MoE 架构不能单独作为新颖性主张。

可争取的贡献是：源侧 velocity 在未配对扰动预测中的独立信息价值、利用该信息的具体路由机制，以及跨条件/时间验证的收益和失效边界。是否足够形成方法论文取决于实证与相对已有工作的区别。

最少报告：主要分布指标、扰动特异指标、可独立定义的结构指标、跨 seed 波动、条件级置信区间、任务分层和失败案例。预注册异质子集上收益与全体非劣效须分别检验；未冻结的测试后分层只能标作探索性分析。

ICML 2027 为目标会场，具体截止日期以官方公布为准。AAAI 2027 主会全文已于 2026-07-28 截止，不作为本计划启动后的降级出口。阴性结果、数据资源或 benchmark 是否达到其他会场要求需另行评估，不自动保证发表。

## 10. 所有实验的落盘要求

每个正式实验目录至少包含：

```text
outputs/<experiment_name>/
  RESULTS.md
  metrics.csv
  config.yaml
  provenance.json
  split_manifest.csv
  predictions/       # 如该阶段生成预测
  figures/           # 如该阶段生成图
```

- `RESULTS.md`：问题、协议、结果、置信区间、限制和继续/停止决定。
- `config.yaml`：冻结参数、任务、指标版本、seeds、预算、置换方案和模型配置。
- `provenance.json`：数据及预测哈希、基因空间、代码版本、环境、拟合范围、预训练来源和运行时间。
- 真实、置换、失败和中止实验都记录；不能只保留成功运行。
- 未运行、未核验、功效不足与实际阴性必须分别标注。
- 执行者不得擅自改为以静态 router 为主线；若需改变 velocity 主线，必须明确向项目负责人提出。
