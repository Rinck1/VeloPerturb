# scNT-seq 修复版 v2：预测改善与增益来源

日期：2026-10-17。固定修复配置/代码提交：`42f3958`。主配置 `configs/w5_scntseq_repair_v2.json`；原始 v1 结果未改。本系列已被观察，以下全部是探索开发，不是独立确认。

## 结果

预先指定的修复候选是 **正则群体 γ + 池化动力学 + 基线中心化 + S/速度双列读出 + 有限时间核**。它在两个区间都降低预测误差，且优于原定同容量 S-only、S+U 对照。

| 方法 | 30→60 MSE | 60→120 MSE | 两区间相对 identity 降幅 |
|---|---:|---:|---|
| identity | 0.579128 | 0.094137 | — |
| S-only 状态读出 | 0.555379 | 0.090804 | 4.10%、3.54% |
| S-only 两参数状态/历史读出 | 0.557102 | 0.092025 | 3.80%、2.24% |
| 同容量 S+直接 U | 0.558531 | 0.101294 | 3.56%、−7.60% |
| **固定修复候选** | **0.532588** | **0.085363** | **8.04%、9.32%** |

修复候选相对一参数 S-only，额外降误差 **4.10%、5.99%**；相对两参数 S-only 为 **4.40%、7.24%**。这些不是两个生物学重复的显著性结果。

候选在运行前已经指定，不是67臂中事后选优。全部67臂的结果在 `outputs/w5_scntseq_repair_evaluation_v2/metrics.csv`；候选通过了预先写定的 v2 描述规则，原 v1 以及 RENGE 的 H1 仍未通过。

## 修复了什么

### 1. 稀疏尾部零斜率不再直接当作零速率

只用0分钟 raw S/U 池化后，按全基因 S 深度归一到1e4，计算：

`γ_g = (U_g + λ·g0)/(S_g + λ)`，`g0 = ΣU_HVG/ΣS_HVG`，固定 λ=1。

零 γ 从 **1025/2000 降到0/2000**。其中291个基因基线未观测到 U，它们的正值由共享先验支持，不是测得真实降解率；未观测 U 的原因（稀疏性、基因结构或定量）本轮没有区分。字段中保留这些基因的索引与支持状态。

### 2. 扣除0分钟的基线估计场

将原始场改为 `v_t−v_0`。同一 γ、同一聚合口径、同一 PCA 坐标相减；不使用未来目标构造基线。

### 3. 固定正则与有限预测视野

所有读出列只用校准源的范数缩放，固定 ridge=1。速度系数非负；通用 S/U 特征允许正负，不再对直接 U 强加物理方向假设。唯一监督仍是15→30分钟，之后不更新参数。

有限时间核为：

`h(Δ)=15·(1−exp(−Δ/15))/(1−exp(−1))`。

在校准时长15分钟保持一致，而长时修正上界约23.73分钟，避免把瞬时速度无限线性延长。这是保守预测先验，未声称学得真实生物学衰减常数。

最终模型：

`z_pred = z_t + h(Δ)·[a_S(z_t−z_0) + a_v(v_t−v_0)]`。

只拟合两个标量，实际 `a_S=−0.0065069`、`a_v=+0.0385033`；速度分支确实非零，不是退回 static。没有训练 router、GFG/JVP 或大网络。

## 消融告诉了什么

| 变体 | 30→60 相对 identity 改善 | 60→120 相对 identity 改善 |
|---|---:|---:|
| 完整修复候选 | +8.04% | +9.32% |
| 不做基线中心化，其余同候选 | +4.07% | +3.52% |
| 改回无界线性时间核 | +11.17% | **−49.01%** |
| 改为硬截断15分钟 | +6.04% | +10.13% |
| 逐细胞均值替代池化动力学 | +6.69% | −0.76% |
| 保留旧 tail γ，其余同候选 | +8.25% | +10.66% |

因此主要性能收益来自**基线校正、保守校准、有限时间视野与群体聚合**。消除 γ 零值解决了一个估计支持度问题，但不能把预测增益主要归功于 γ 正则化；旧 γ 的对应模型还略好。

## 更强机制对照：净 velocity 仍非唯一解释

独立的后续机制诊断不改变原67臂，使用相同两参数预算、同 ridge、同时间核：

| 机制对照 | 30→60 MSE | 60→120 MSE |
|---|---:|---:|
| 修复候选 | 0.532588 | 0.085363 |
| 非线性 S-only 动力学分量 | 0.551642 | 0.090695 |
| S + U驱动分量，不减γS | **0.531914** | **0.084048** |
| S + 仅当前 U 总量（基线 U 基因组成） | **0.499728** | 0.092894 |

- 非线性 S-only 使用共享0分钟 γ，但不读取当前 U。候选在两个区间均更好，收益不是简单增加一个 S 非线性特征就完全解释。
- U驱动分量为同一源规范化下 `W[U/(1+S)]` 相对基线的变化。它略优于净速度，说明当前没有证据表明减去γS是收益的必要步骤。
- U总量对照保留当前全基因 U/S 总量比，只替换 U 的基因组成为0分钟组成。它第一段很强、第二段较弱，平均 MSE 也低于候选。尚不能证明新增收益需要逐基因 U 组成；全局 U 量/深度及其生物学或技术来源需要继续分开。

当前最准确的判断是：**基线校正、有限视野的群体动力学校正，在这条探索序列里有可用预测收益；净 velocity 的独特性、U基因组成的独特贡献及跨数据泛化尚未建立。** 不把这一结果直接升级成命运/router 主张。
