## 结论

继续推进，但先修正检验、补三个缺口、完成 GFG 公平重训，不直接增加 router 或专家训练规模。目前没有建立 velocity 特异性预测增益；现有阴性也不足以证明 U 在表达状态之外完全没有未来信息。

原主张需要依次成立：U 有额外信号，GFG 能提取，信号预测响应模式，router 利用该信号改善留出预测。多峰终态本身不能替代这四项证据。

两细胞合成复核：同一细胞 U=[10,5]、S=[5,5] 单独输入时 innovation=[0,0]；与 U=[0,20]、S=[5,5] 同批时变为 [5,-7.5]。这是批次依赖的数值验证，不是生物学阳性。

MeRLin 旧统计量是逐基因偏相关的带符号平均。稀疏、异号、多基因交叉映射和离散类别信号可能不被该统计量捕获。功效注入沿未来表达残差作用于全部基因，只证明对该信号家族的敏感性。[统计与注入代码](../../../scripts/phase0/w2_leadlag_power.py)

旧置换直接打乱未来 Y，同时破坏 Y 与被控制 S 的关系，不能自动当作“给定 S 后增量为零”的有效零分布。新版须验证相应条件零假设及模型假设；回归复现旧数值不等于检验校准通过。

## 三个缺口

### 多基因低维动力学

现有 MeRLin 数据可检验。先在训练克隆的独立计数拆分中学习可重复方向，再评价留出克隆上的稳定性与未来预测增量。所有残差、PCA 和超参数只在训练部分拟合；不能把反复划分当作新增独立样本。

可靠方向不等于命运方向；κ 阳性只说明 U 的候选增量，随后必须检验 GFG velocity 是否保留它。CCA 置换需处理残差引入的依赖和多成分检验。[Winkler 等方法论文](https://www.sciencedirect.com/science/article/pii/S1053811920305516)

### 离散响应类别

最贴近 router，但先解决标签来源与样本量。MeRLin 原文描述四种 persister 程序，另有五个 barcode group；第五组包含敏感和低丰度细胞。neural-crest-like 为脂代谢与 PI3K 两组共享特征，不是额外互斥类别。Day21 部分组稀少。不能将现有五套 signature 取最大值冒充五类命运。

获取作者标签或可复现映射，明确是克隆分组还是表达状态，报告各类、各克隆计数。按克隆留出，对比 S、S+κ、S+εS 的未来构成预测；低计数比例需报告不确定性。无法恢复标签时，停止该项，不人为制造类别。[MeRLin 论文](https://link.springer.com/article/10.1186/s12943-026-02622-9)

### 短时群体动力学

RENGE 已具备输入，但须校正 noisy S 控制。工具变量两阶段都应包含外生 ΔU，报告第一阶段强度，并验证计数拆分、共享对照和归一化是否破坏误差假设。ΔS 替代 ΔU 是必要自检，不是校正正确的充分证明。

主分析使用预定全基因面板；响应基因分析需额外独立选择数据，不能选完基因后删除唯一的工具变量 C。原始未来标签打乱仅保留为配对破坏描述，不作条件增量的主显著性依据。结果若阳性，首先支持短时群体动力学，不自动支持逐细胞长期命运。

## 执行顺序与决策

1. 检验底座：固定 S 的 U-only 对照、冻结源侧变换、统一坐标、独立 U/S 拆分、条件零假设的合成校准。
2. 运行多基因与短时群体检验，同时核查离散标签；补稀疏、异号及零增量功效情形。
3. 公平重训原版 GFG，使用其原始 moments 预处理，并对 foundation 权重做独立审计。当前 MouseBrain 权重迁移到人类原始 U/S 的结果不能代表方法普遍失效。
4. 依据证据决定完整版 GFG 和 router 的投入，不以未校准的显著性解锁全量训练。

| 后续结果 | 下一步 |
|---|---|
| 多基因与类别增量成立，GFG 保留增量 | 恢复动力学 router 主线 |
| 只有短时群体增量成立 | velocity 定位为短时响应与路径的辅助监督 |
| 原始 U 增量成立而 GFG 不成立 | 聚焦速度估计器的提取瓶颈 |
| 所有检验阴性且对预定信号家族功效充分 | 收束为适用边界研究，不无限增加模型复杂度 |

MeRLin 原先的 75 个 confirmation 克隆已被 W1/W2 使用，不能再次称为封存确认集；重划分只能提供开发期验证，最终确认需要独立样本或数据集。
