# W13：从端点混合到真正的连续时间模型

本轮做用户指定的1/2/4，不做第3项外部基线与direct-U适配。
完整执行顺序、配置和实际结果分别在 `PLANS/w13_time_dynamics.md`、
`configs/w13_scifate2_time_v1.json`、`outputs/w13_time_program_v1/`。

## 核心定义

保留已有效的源侧soft router：q_ik = q(k | z_i(0), v_i(0))。
q在一条预测轨迹上固定，各专家分别积分，不把不同专家场平均后只走一条轨迹。
局部kinetic信息只进入router；当前实现没有原GFG、decoder JVP、EM老师或门控。

将位置分为全局均值和模式内残差：

    m(t) = mean_i z_i(0) + h(t) * global_rate
    z_ik(t) = m(t) + y_ik(t)
    y_ik(0) = z_i(0) - mean_i z_i(0)
    dy_ik/dt = h'(t) * [F_k(z_ik(t), t) - mean_i sum_k q_ik F_k(z_ik(t), t)]

h为原均值分支冻结的elapsed-time核，h(0)=0、h(24h)=24h；衰减版本为
24(1-exp(-t/24))/(1-exp(-1))，单位为有效小时。F使用PCA单位/有效小时，
乘h'(t)后是PCA单位/实际小时。源侧RNA kinetics不是直接相加的物理位移。

因为q固定，sum_k q_ik=1，残差混合均值的导数严格为零。RK4各子步均使用当前
全混合群体的同一可微中心化，因而保持这个不变量；均值m(t)解析计算而非数值积累。
训练仍沿用成功配方的随机源batch中心化，部署采用完整源群体中心化；这对应既有
随机batch目标，不声称是无偏完整群体目标。

这是一个**群体耦合ODE**：中心化项取决于整批粒子及固定q，不能把源群体独立切块
积分再拼接并声称同一预测。部署代码一次计算完整源群体。有限网络权重、正归一化尺度、
SiLU和有界tanh输出给出光滑且有界的有限维场，任意有限预测区间上解存在且唯一；
这不等于真实生物路径可由每日未配对终点唯一识别。

## 与端点模型相比新增什么

骨干和8个专家复用原76,248参数的结构。新增4维时间特征到128维隐藏层的线性投影，
零初始化，512参数，总76,760。专家读各自当前状态和elapsed-time；router只读出发状态。
保留原始源上下文和累计elapsed-time时可以分段重启同一ODE；中途重新路由或将h重置
为零，会改变模型，不能作为同一轨迹的继续积分。

小型ODE和端点时间对照从同一个b1/36k模型初始化，Adam同等重置，学习率1e-4，
各追加4000步。端点时间对照在初态及区间中点时间评价相同场，然后作一次位移；
ODE使用最大6小时的RK4、通过全部子步反传。两者参数和更新次数相同，ODE每步
计算量更大，不能说FLOPs或墙钟预算相同。所有版本均使用相同冻结均值。
