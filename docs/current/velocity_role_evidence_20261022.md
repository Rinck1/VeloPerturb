# RNA velocity在扰动预测中应该承担什么角色

更新：2026-10-22。结论针对当前已测估计器/表示和任务，不替换原始实验记录。

## 当前判断

已测用途里，**训练时的动力学程序关系先验**最接近积极线索，但多轮扩大没有稳定建立velocity特有收益。
不能把初速度直接当终点命运标签；下一阶段不再默认扩大关系损失，方向性需要独立时间证据。
“velocity很重要”是一条待验证的研究假设，不应反过来要求所有结果都支持它。

后续 [W15R/S 的 72 模型扩大](w15r_s_velocity_expansion_20261022.md)已经完成：
局部去噪和增加关系权重都未扩大优势。技术方向重复性改善，不等于扰动预测改善。
[W15T 条件路由](w15t_conditioned_velocity_router_20261022.md)也已完成：无图加 c +0.591%、真实图加 c +0.379%，均三个 seed 同向；
但真实 velocity vs 有条件无图仅 +0.487%，vs打乱/U图 +0.536%/+0.692%，均有负 seed。
条件接口本身有小幅帮助，velocity 增量没有扩大，不能混合归因。

[W15U/V/W最新扩大](w15u_v_w_expansion_20261022.md)已完成：对比关系监督vs无图+0.714%且三seed正，
但vs打乱−0.039%；目标域无JVP计数估计器vs无图+0.590%、vs打乱+0.084%，仍不稳定。
去均值后的形状没有稳定胜所有对照；时间校准的大均值收益也可由S单项解释。
这进一步限制“动力学关系就是终态响应归属”的假设，但不是velocity在所有任务无用的证据。

[W15X/Y/Z训练内筛选与二阶探针](w15x_y_z_u_increment_20261022.md)也已完成：
三种U家族的内层基因筛选优势均未迁移到留出KO；最终候选不能当作阳性动态程序。
6→24h和0→6h的正向状态-速度协方差均被拟合为零系数，反号也未改善留出方差预测。
这是具体残差筛选和共享系数通量探针的阴性，不证明所有U信息或所有velocity估计器都无用。

[W16固定三折扩大](w16_perturbation_execution_20261022.md)已完成63模型/1323预测：
真实图vs无图−0.366%、vs U图+0.106%、vs三打乱均值−0.049%，95%区间均跨零。
因此原7开发KO的关系监督线索没有在63开发KO复现为稳定优势，不继续原样扩容。
同轮scNT-seq低维读出复现剪接v相对S校正+4.400%/+7.239%，但仍略弱于U驱动。
标记参照15min有60.15%支持基因负合成估计，未能成为可靠的方向真值。

## 为什么瞬时速度不等于扰动效应

记某条件c下的动力学为`dx/dt=f_c(x,t)`。未来位移为：

`x_c(t+Δt)−x_c(t) = ∫ f_c(x_c(s),s) ds`。

只有起点的速度，不能确定整个积分，更不能仅靠对照条件的`f_control`确定未知条件的`f_c`。
这是任务可辨识性的区别，不是选一个更大router就能自动补出的信息。

Traxler 6→24h的源细胞在6h时已处于KO背景，所以这里的velocity若正确，反映的是
**该扰动下当时的总转录动态**，不能自动称为“无扰动内源分量”。
它可能提示响应阶段/局部走向，但24h终态还取决于后续变化的条件动力学。
原计划中的`v_int + F_perturb`分解若没有额外对照和约束，通常不能从未配对快照唯一识别。

另一点是信息和归纳偏置：若`v=h(S,U)`且估计器冻结，则v不增加完整S/U之外的信息。
可能的价值是降低学习难度、突出局部关系、抑制无关变化，而非创造新模态。
降维U50和v50不是完整S/U，不能直接套用“某一50维表示一定信息更多”的排序。

## 文献提示：局部关系是一个合理用途，但不是新发现

CellRank用表达邻域加velocity构造局部有向转移，再沿图聚合命运概率；
它依赖足够覆盖中间状态的流形以及有用的局部方向，不是只凭起点向量直接预测任意扰动终态。
这支持“先判断局部动态是否可信，再讨论长程命运”的方法顺序。
[CellRank原论文](https://www.nature.com/articles/s41592-021-01346-6)。

Cell2fate把velocity分解为可解释动态模块，说明从动力学中提取程序而非使用全部噪声向量
是已有研究路径；但它的模块有显式生物物理建模，并不等同本项目从训练响应SVD得到的5条轴。
[Cell2fate](https://www.nature.com/articles/s41592-025-02608-3)。

2026-10-21发表的DynaVelo联合建模RNA和TF motif动态，既用velocity方向监督，
也约束两模态的细胞间速度相似关系，再通过改变状态输入分析扰动后的速度变化。
这给关系监督提供概念参照，但不是同一个未见KO终态泛化任务，也不能证明我们的方法已有效。
[DynaVelo](https://www.nature.com/articles/s41587-026-03348-1)。

以上文献与我们的结果共同提示：**RNA velocity更自然的监督对象是局部动力学/转移结构，
不天然等于跨长时间和跨干预的最优运输速度**。这句话是基于方法区别作出的判断，不是本项目已证明的定理。

## GFG应该怎么接，不能偷换什么

W15M–T均未使用GFG。当前解析残差的失败，不能证明目标域重训GFG也会失败；
同样，换成GFG重建得好，也不能证明方向正确或扰动预测会改善。

若走改版GFG，保留用户确定的“不用JVP、目标域重训”路线。应先明确它输出的是：

- 有剪接意义、经过噪声处理的瞬时RNA变化；还是
- 训练条件未来均值位移的任务表示；还是
- 响应程序的局部相似几何。

这三者可以组合，但不能用同一个“velocity”名称掩盖目标变化。
尤其是仅用`U−γS`教一个速度头，再让router重建这个头，不会自动增加独立时间证据。
方向身份需要短时间锚/代谢标记等外部证据；关系身份需要在同预算下优于U/S及打乱关系。

## 新的失效线索：程序方向对计数噪声敏感

[W15Q源侧拆分](w15q_velocity_countsplit_20261022.md)已完成：592个源细胞，五次重复，不看未来。
S/U都拆成两半时，S状态50维余弦0.927；velocity程序5维0.505，U程序5维0.783。
velocity程序两半负余弦14.65%，U程序2.31%。这不是生物学准确率，但说明当前逐细胞程序不能当高精度监督。
50维U和velocity重复性接近（0.570/0.560），噪声差异并非所有表示都成立。

因此后续估计器的合理任务是**在保留U敏感性和细胞差异的同时做局部去噪，并表达不确定度**；
不能通过忽略U或只给每KO一个向量“提高稳定性”。噪声减小后仍需单独评价方向和扰动任务。

## 接下来的优先级

[W15P对照已完成](w15p_velocity_graph_controls_20261022.md)：vs三套全局打乱均值+0.654%、
vsS局部打乱+1.269%，均三个seed同向；但某一全局打乱几乎持平，原vs无图/U图仍不稳定。
因此保留关系监督候选，不原样扩大K或参数量。
随后固定局部去噪/增强约束网格已完成，但均未胜原图和无图；不继续沿同一方向扩大。
q(k|S,U,c) 的四臂匹配设计也已完成，没有扩大 velocity 特有收益。
随后目标域无JVP计数估计器已在W15V从零重训，仍未扩大真实v相对打乱的差距；不是原版GFG或联训。
不继续原样加K/λ/容量。随后训练条件内识别U时间增量的W15X已完成，但未通过外层筛查；
没有将候选基因直接用于新增模型。两窗口方差探针也未建立正向增量。
下一建议是先建立有独立局部时间/代谢标记支持的速度估计，而不是继续把计数重建当方向监督。
W16已尝试上述标记工作模型，但出现明显失配，尚未获得可用于速度蒸馏的可靠参照。
扰动三折也未保持关系收益；下一实验需要针对短时机制或估计假设重新选择，
不能把已完成验证再写成待运行，也不因为某个KO好就只筛那个KO。
