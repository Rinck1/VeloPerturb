# CellFlow动力学插件：固定L2开发结果

群体动力学token超过static，但尚未超过S摘要；群体摘要本身仍是可行解释。

同一128×2基座、固定5000步和学习率；六臂各三训练seed。复用W13源细胞ID和同一目标缓存，先冻结18模型的216个窗口/时钟预测，再统一评分。以下主结果是三seed等权混合分布，不是挑选最好seed。动力学为解析剪接残差的PCA投影与源参考相减，不是原版GFG/JVP。

## 机理与范围

S摘要检验是否仅需要额外群体信息，直接U检验速度构造是否优于第二模态本身；逐细胞kin与源群体内shuffle单列，只使用一个固定置换perm_seed0，三训练seed不等于三个置换。sci-FATE2只有一个条件，因此没有检验群体token跨条件对应关系CF-H3。

这是同系列开发结果。窗口有重叠，训练seed也不是独立生物重复；不把这些描述性差值当作生物重复置信区间。模式比例使用训练目标k-means的表达成分，不是已观测细胞命运。

群体token遮蔽接口已准备，但本轮没有执行任何冻结权重的新干预或额外训练。
