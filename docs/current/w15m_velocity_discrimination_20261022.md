# Velocity 的用途判别：方向、幅度与训练辅助

2026-10-22。Traxler 6→24h，实际跨度18h；56训练KO、7开发验证KO、7保留测试KO。
速度来自解析S/U，不是GFG。下述结果只评价这套速度及其5维训练响应程序表示。

后续更新：已完成[真正辅助损失的四臂实验](w15n_velocity_auxiliary_20261022.md)，
真实velocity未胜打乱及U辅助。本页冻结输入开关现象不等价于正式辅助训练有效。

## 结论

当前证据更支持把velocity作为响应程序上下文或训练辅助，不支持把它直接作为未来位移箭头。
整体速度幅度不够用，去掉每条程序轴的正负号仍能预测；原模型对逐细胞velocity精确对应的必要性也未建立。
因此router继续保留，但不把ODE方向硬绑到当前velocity。

## 一、三种表示重训：9个新模型全部完成

保留共同S50/U50输入、5个额外槽、389,704参数、K8、相同初始化与训练采样；
每种新表示三个seed，各5000步。单位方向、S+U、U程序、原打乱臂复用12个既有模型。
所有百分比均为同KO/seed配对相对Energy改善的平均，正数为好，不是两项总体均值的比值。

| 额外velocity表示 | vs S+U | vs原单位方向 | vs U程序 | vs三套已训练打乱均值 |
|---|---:|---:|---:|---:|
| 原有符号单位方向 | +0.401% | 0 | +0.027% | +0.486% |
| 无符号程序：单位方向逐轴取绝对值 | +0.711% | +0.307% | +0.336% | +0.797% |
| 仅程序速度模长 | −0.121% | −0.540% | −0.497% | −0.030% |
| 程序方向与模长 | +0.082% | −0.326% | −0.293% | +0.169% |

无符号表示相对原方向的三个seed为+0.673%、−0.539%、+0.787%；5/7 KO在seed平均后改善。
它是值得验证的候选，不是已经稳定胜出的新主模型。原单位方向相对S+U仍为三个seed均正。
“无符号程序”保留不同响应轴的相对强度，不能与只保留一个总模长混为一谈。
共同S/U输入仍可携带与方向有关的信息，因此该消融只检验显式方向槽的额外价值。

## 二、冻结模型：逐细胞路由重要，但正确velocity方向并非必要

三个父模型权重、全部专家终态固定，不新增ODE积分，仅修改额外5槽或q。
以下改善相对原有符号velocity模型，不是相对静态模型。

| 推理改动 | Energy改善 |
|---|---:|
| 再次单位化 | 0（原输入已经单位化） |
| 关闭额外velocity槽，保留S/U | +0.395% |
| 方向反转 | +0.555% |
| 方向逐轴取绝对值 | +0.862% |
| 用源KO群体方向替换逐细胞方向，仍逐细胞路由 | +0.845% |
| 替换为U程序 | −0.056% |
| S近邻配对内交换方向 | +0.046% |
| 三套KO内细胞打乱方向，改善等权平均 | +0.151% |
| 全源群体平均q替换逐细胞q | −21.970% |
| 均匀q | −26.866% |

反转、关闭、无符号、源群体方向四种改动的平均改善均在三个seed上为正。
“群体方向”只平滑velocity附加槽，q仍读取每颗细胞S/U；它与把所有细胞q平均掉是不同操作。

已有的“真实velocity重训优于打乱velocity重训”与本次“冻结后打乱不下降”并不矛盾：
前者同时改变了整个训练过程及专家，后者只改既有模型的推理输入。
合起来，结果提示训练期的表示/正则化作用，而非部署时必须保留精确的单细胞速度配对。

例如，真实velocity训练、推理将额外velocity槽置零，相对重新训练的S+U对照仍改善0.793%，
三个seed为+0.889%、+1.198%、+0.292%。相对U程序平均+0.420%，并非三个seed均正。
这只是冻结干预给出的训练辅助候选，尚未训练专门的退火/蒸馏方案。

## 三、极简方向探针：不能直接沿当前velocity修正终点

先以训练KO共同位移预测目标均值，再在5维响应子空间增加一个全局标量乘源方向。
标量、共同位移、响应轴都由训练KO拟合；不含ESM，不与完整神经网络作性能排名。
下表指标为均值MSE，改善按验证KO配对等权计算，不是Energy。

| 修正 | 训练系数 | 验证均值MSE | vs共同位移改善 |
|---|---:|---:|---:|
| 共同位移 | 0 | 0.231020 | 0 |
| 非负系数×正向velocity | 0 | 0.231020 | 0 |
| 非负系数×反向velocity | 0.146565 | 0.233435 | −0.988% |
| 允许符号的velocity | −0.146565 | 0.233435 | −0.988% |
| 允许符号的U程序 | −1.262659 | 0.214604 | +4.647% |

当前相对velocity既不支持正向线性推进，训练拟合出的反向修正在验证上也无益。
这不等于所有RNA速度或重训GFG都无效；此处测的是程序子空间内的扰动差异与18h总位移。

## 用法建议

1. 不增加当前velocity的硬cos约束、固定内源方向或沿途方向损失。
2. 保留S/U驱动的逐细胞router；把velocity当作低维响应程序上下文，而不是逐细胞命运标签。
3. 下一次固定比较优先考察：单位程序、无符号程序、velocity训练辅助但推理淡出、
   逐细胞路由加源群体动力学平滑。后三者不能用本次干预中最好的分数代替新的固定验证。
4. GFG目标域重训之后复用同一组判别，检验它是否真的改善方向与增量，而不是只更换估计器名称。
