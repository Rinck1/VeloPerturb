# CellFlow 开发基座选型

2026-10-21，GPU0顺序完成四个官方CellFlow static候选，约529秒。
只以r4三个5h开发窗口的decay Energy等权均值选型，全部使用seed0和同一抽样。
没有运行或查看kin插件成绩来选择骨干。

| 候选 | 参数量 | 更新步数 | 开发Energy↓ |
|---|---:|---:|---:|
| 128×2 | 121,138 | 5,000 | **0.643698** |
| 256×3 | 433,970 | 10,000 | 0.673767 |
| 512×3 | 1,485,106 | 10,000 | 0.656273 |
| 官方默认hidden/time宽度1024×3 | 9,594,930 | 10,000 | 0.685502 |

按事先约定选择128×2。L2插件和L3合并模型继承其骨干、优化器及训练预算，不另选主干。
这只是开发基座配置冻结，不是完成全部CF-3，更不是velocity阳性或最终外部方法比较。
本轮覆盖的预算下，大网络没有带来更优的开发指标；不外推为大模型普遍无用。

本轮内部选型使用evaluation_seed=0；旧W13使用另一组冻结抽样。
后续跨L1/L2/L3比较会统一到W13源细胞ID和目标缓存，不直接用本表与旧W13分数判断胜负。
每个候选均先冻结六窗口×两时钟的12份预测再评分；全部候选记录保留。
