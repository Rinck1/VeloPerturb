# 预注册：短时群体速度能否提前预示扰动响应

状态：**草案**（W4-2 冻结后改为"已冻结"，并写入冻结提交号）
作者：Claude（规格）、Rinck（负责人）　|　起草日期：2026-10-15　|　冻结提交号：〔W4-2 填〕

本文件在读取任何复制集扰动效应之前冻结。冻结后不修改假设、指标、对照、超参数或成功标准；任何偏离写进第 8 节"偏离记录"，并把相应分析标为探索性。

## 1. 主张

扰动后的短时间内，由 U、S 计算的**群体**RNA 速度，能比只用当前 S 更准确地预测扰动群体在下一时间点的状态均值；这部分增益来自 U 本身，而且随预测跨度变长而衰减。

本预注册**不**检验逐细胞或逐克隆的命运预测。

## 2. 假设

| 编号 | 假设 | 类型 |
|---|---|---|
| **H1** | 在 RENGE 的 day2→3、day3→4 上，`vel_pool` 同时优于 `static` 和 `vel_pool_Uswap` | **主假设** |
| H2 | 相对 `static` 的增益随预测跨度 Δ（1、2、3 天）增大而下降 | 次要 |
| H3 | day2→3 的增益大于 day3→4（越早偏离稳态越强） | 次要 |
| H4 | 状态流换成冻结的 foundation 编码器后，`vel_pool` 相对 `static` 的增益仍大于 0 | 次要 |
| H5 | sci-fate 中，内含子 U 群体速度能追回代谢标记实测速度相对 `static` 增益的一部分（报告比例） | 描述性 |
| H6 | MIX-seq 曲美替尼时间序列上重复 H1、H2（以细胞系为单位） | 次要（数据可得时） |

## 3. 数据与单位

### RENGE（主数据）

- 来源：GEO GSE213069；day2、day3 按 W4-1a 新处理，day4、day5 用已发布的 `processed_release_v1`。
- **单位是 TF。** 纳入条件：在 t 和 t+Δ 两个时间点都至少有 50 个通过 QC 的单一 guide 细胞。纳入的 TF 列表：〔W4-2 按 QC 结果填〕。
- 对照条件（AAVS1、CTRL）始终只用于训练，不作为留出单位。
- 复制集时间段：day2→3、day3→4。开发集：day4→5（已多次使用，不参与 H1 判定）。
- 已知限制：W2/W3 中所有 TF 的 day4、day5 数据都被看过，day3→4 的目标时间点 day4 不完全是新数据；但"day3 的速度预测 day4"从未计算过。原 confirmation TF 在 day2、day3 上的数据未使用过，按普通单位纳入。

### MIX-seq（H6）

单位是细胞系（纳入条件：每个时间点曲美替尼组和 DMSO 组都 ≥ 20 个细胞；列表〔W4-2 或数据到位时填〕）。时间段：3→6、6→12、12→24、24→48 小时。

### sci-fate（H5）

单位是时间点（0、2、4、6、8、10 小时，共 5 个相邻时间段），只做描述性比较。

## 4. 流程（固定）

每个时间段 t→t+Δ，对每个留出 TF c 做一折：

1. **拟合**，只用时间 t、排除 c 的源细胞（训练 TF 加对照）：
   - 2000 个 HVG（log1p 归一化 S 的方差排序）；
   - S 文库归一化到 1e4（U 用同一个 S 文库因子）；
   - log1p 后的 PCA-50；
   - 每个基因的 γ_g（上尾 OLS，分位 q=0.05，与 `fit_gamma_tail` 一致）；
   - 状态簇 k-means（k=8）。

   全部冻结。时间 t+Δ 的任何数据不参与拟合。
2. **状态**：z_i = PCA(log1p(归一化 s_i))。
3. **速度**：v_ig = u_ig − γ_g·s_ig；投影 ż = W·(v / (1+s))。
4. **群体量**：
   - z̄_c,t；
   - `vel_pool`：先合并计数再按第 3 步计算；
   - `vel_mean`：逐细胞投影后取平均。
5. **预测器**：ẑ_c,t+Δ = z̄_c,t + A·v̄_c,t + B·[z̄_c,t, e_c] + b。岭回归，α ∈ {0.1, 1, 10, 100, 1000}，用内层"留一个训练 TF"选择。e_c 用 ESM2 条件嵌入（StandardScaler 只在训练 TF 上拟合）。`static` 臂去掉 A 项，其余完全相同。
6. **目标**：时间 t+Δ 条件 c 的状态均值 z̄_c,t+Δ。用同一冻结 PCA，对 t+Δ 的 S 做同样的归一化和 log1p。
7. **随机性**：seed 0–3 只影响 k-means 初始化和 U 交换的平局处理。指标在**对 4 个 seed 的预测取平均之后**计算；seed 不是生物学重复。
8. 先保存全部臂、全部折的预测并记录哈希，然后才读取目标。

### 对照臂定义

| 臂 | 定义 |
|---|---|
| `static` | 无速度项 |
| **`vel_pool`** | 主臂 |
| `vel_mean` | 逐细胞速度平均 |
| `vel_pool_Uswap` | 条件 c 的 U 计数换成"时间 t 源 S 均值（PCA 欧氏距离）最近的另一条件 c′"的 U，按受体 U 总量缩放；S 不变 |
| `pseudo_S` | 训练源 S 空间里 30 近邻均值减自身，按条件平均 |
| `learned_head` | W3 no-JVP 学习版速度头（冻结 innovation），次要比较 |
| `empirical_disp` | z̄_c,t − z̄_c,t−1，仅在有 t−1 时计算，上限参照 |

## 5. 指标与统计

- **每个 TF 的误差**：L_arm,c = ‖ẑ_c,t+Δ − z̄_c,t+Δ‖²（50 维求和）。
- **每个 TF 的相对增益**：g_c = (L_ref,c − L_vel_pool,c) / L_static,c。ref 为 `static`（比较一）或 `vel_pool_Uswap`（比较二）。
- **汇总**：对每个 TF，先在两个复制时间段上取平均，得到 ḡ_c；再对 TF 等权平均，得到 Ḡ。
- **区间**：对 TF 做 cluster bootstrap，10,000 次，取 95% 百分位区间。
- **检验**：对 ḡ_c 做单侧 Wilcoxon 符号秩检验，α=0.05。

### H1 成功标准（两个比较都要满足）

1. Ḡ 的 95% 区间下限 > 0；
2. Wilcoxon p < 0.05；
3. day2→3、day3→4 两个时间段各自的点估计都 > 0。

| H1 结果 | 结论写法 |
|---|---|
| 比较一、二都满足 | 短时群体速度的增益成立，且来自 U |
| 只有比较一满足 | 速度类特征有帮助，但不能归因于 U |
| 比较一不满足 | 短时群体速度增益不成立 |

### 次要假设

- **H2**：每个 TF 在 Δ=1、2、3 天的增益上拟合斜率，TF bootstrap 后平均斜率的 95% 区间上限 < 0 为成立。Δ=3 只有 day2→5。
- **H3**：TF 配对差 g(2→3) − g(3→4) 的均值和 bootstrap 区间，区间下限 > 0 为成立。
- **H4**：同 H1 比较一的三条标准，状态流换成 foundation 编码器。编码器输入格式无法匹配时记为"未执行"。
- **H5**：追回比例 = (L_static − L_内含子速度) / (L_static − L_实测速度)，逐时间段报告，另报告两种速度的 cos。
- **H6**：同 H1、H2，单位换成细胞系，4 个相邻时间段合并。H2 的跨度用 log(小时)。

次要假设不做多重比较校正，结论写"支持/不支持"，不写"证明"。

## 6. 结果与去向

| 结果 | 去向 |
|---|---|
| H1 成立（两比较），H2 成立 | 短时线作为论文主结果，扩展外部数据 |
| H1 只有比较一成立 | 速度特征有用但不特异；并入"适用边界"分析论文 |
| H1 不成立 | 短时线阴性；并入"适用边界"分析论文，作为"群体短时尺度也未测到"的证据 |

无论结果如何，全部臂、全部时间段、全部 TF 的结果都原样报告。

## 7. 功效说明

RENGE 预计 18–23 个 TF。用 Wilcoxon 检验时，若 TF 层面效应量（均值/标准差）约 0.6，功效约 0.8。W3 开发集的解析速度在 4 个 TF 上相对 static 平均降低约 2.3%，TF 间差异未知；如果真实效应只有这个量级，H1 可能功效不足。这是已知风险，不因此修改标准。
