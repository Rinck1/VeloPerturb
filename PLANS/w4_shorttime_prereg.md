## 1. 主张

待检验主张：扰动后的短时间内，由 U、S 构造的**群体动力学特征**，能比只用当前 S 更准确地预测扰动群体在下一时间点的状态均值，并优于源状态匹配的 U 交换对照；其增益可能随预测跨度变长而衰减。

区分两个问题：**U 是否提供 S 之外的预测信息**，以及**把 U、S 转成速度是否优于直接使用 U**。固定 γ 时 v=U−γS 是已有信息的重表达，不产生新信息。H1 的 U 交换是匹配压力对照，不能单独证明因果性或完成精确条件独立检验；H7 的直接 U 基线用于补充分解。

本预注册**不**检验逐细胞或逐克隆的命运预测。

RENGE 的源是当前时间点已经接受相应 KO 的群体，属于已观测早期响应后的短时推进；不把这些结果解释为仅凭未扰动对照即可预测任意新扰动的 de novo 响应。

## 4. 流程（固定）

每个时间段 t→t+Δ，对每个留出 TF c 做一折：

H1 的扰动训练 TF 限于已冻结的 H1 共同 QC 名单中除 c 的其余 TF；不额外加入未纳入该名单的 TF 来补源拟合或监督标签。控制条件仅在本区间源、目标各至少 1 个合格细胞时纳入。H2 后续使用自身共同 QC 名单，在全部跨度上保持相同的训练/留出 TF 规则。该训练范围于冻结前明确，协议锁中 H1 固定为 `training_TF_scope='H1_TFs_only'`。

1. **源变换拟合**，只用时间 t、排除 c 的源细胞（训练 TF 加对照）：
   - 每个细胞以全部对齐基因的 S 总量归一化到 1e4（U 用同一个 S 文库因子）；先归一化，后取 HVG，不以 HVG 子集重新估文库大小；
   - 2000 个 HVG（log1p 归一化 S 的方差排序）；
   - log1p 后的 PCA-50；
   - 每个基因的 γ_g（两端尾部 OLS：S 的 ≤5% 和 ≥95% 分位细胞合并，分位 q=0.05，与 `fit_gamma_tail` 一致；正 S 细胞不足 10 或分母为零时 γ=0，记录数量）；
   - 状态簇 k-means（k=8）。

   全部冻结。时间 t+Δ 的任何数据不参与**上述源变换**拟合。每个 outer 折只拟合一次源变换；内层 CV 共用该变换，所以 inner 留出 TF 的源 S/U 参与无监督源变换，但其目标不参与该 inner 折预测器训练。outer 留出 TF 的源 S/U 只作变换和推理，不参与源变换拟合。
2. **状态**：z_i = PCA(log1p(归一化 s_i))。
3. **速度特征**：v_ig = u_ig − γ_g·s_ig；投影 ż = W·(v / (1+s))。这里 W 是 PCA 载荷，投影不减 PCA 均值，且求导时固定源侧文库因子。β 固定为 1，故是相对动力学单位，不声称已校准为“每一天的实际速度”；每个跨度的 A 由训练 TF 估计。
4. **群体量**：
   - z̄_c,t；
   - `vel_pool`：先对条件内所有细胞的 **raw counts** 分别求和得 U_sum、S_sum，以全部基因 S_sum 的总量把二者归一到 1e4，再取 HVG，计算 W·[(u_pool−γs_pool)/(1+s_pool)]；
   - `vel_mean`：逐细胞按第 1–3 步归一化、投影，再对细胞等权平均。

   `vel_pool` 是池化动力学**特征**，一般不等于目标 mean(log1p S) 的导数：raw pooling 引入 S 文库深度权重，且 log1p 非线性。`vel_mean` 对应固定归一因子下的逐细胞导数平均。二者都预测同一细胞等权状态均值，不偷偷更换目标。
5. **预测器**：ẑ_c,t+Δ = z̄_c,t + A·v̄_c,t + B·[z̄_c,t, e_c] + b。岭回归，α ∈ {0.1, 1, 10, 100, 1000}，用内层"留一个训练 TF"的均值平方误差选择，平局选较大的 α。所有非恒定输入块统一 StandardScaler，scaler 在每个 inner 折仅拟合 inner 训练 TF/对照；选择 α 后在 outer 训练 TF/对照重新拟合 scaler 和 ridge。e_c 默认现有 ESM2 条件嵌入。**训练 TF 的 t+Δ 目标可用于 ridge 拟合及内层 CV**，这是监督预测任务的合法训练标签；outer 留出 TF 的目标不得参与任何拟合、调参或早停。`static` 臂去掉 A 项，其余相同；不把信息集不同导致的输入维度差说成参数量完全相同。
6. **目标**：时间 t+Δ 条件 c 的状态均值 z̄_c,t+Δ。用同一冻结 PCA，对 t+Δ 的 S 做同样的归一化和 log1p。
7. **随机性**：seed 0–3 只影响 k-means 初始化和 U 交换的平局处理。指标在**对 4 个 seed 的预测取平均之后**计算；seed 不是生物学重复。
8. 每折的 held-out 目标在该折训练/预测路径封存。先保存全部臂、全部折的预测并记录哈希，再由独立评估入口读取 held-out 目标计算指标。其他 TF 的目标可以在不同折充当训练标签，因此不声称“全流程未读任何未来时间点数据”。

### 对照臂定义

| 臂 | 定义 |
|---|---|
| `static` | 无速度项 |
| **`vel_pool`** | 主臂 |
| `vel_mean` | 逐细胞速度平均 |
| `direct_U_pool` | 与 `vel_pool` 同一状态/ESM 输入，额外 50 维为 W·log1p(u_pool)，不减 PCA 均值；不估 γ、不构造净速度。相同 ridge 网格、CV 折和搜索预算 |
| `vel_pool_Uswap` | 从当前 outer **训练源** TF/对照中，选时间 t 源 S 均值（PCA 欧氏距离）最近且不同于受体 c 的供体 c′；以供体 raw pooled U 的基因组成替换受体 U，按受体 raw U 总量缩放，再用受体 S 文库因子归一化。S 不变；供体可重复，平局按 seed 处理 |
| `pseudo_S` | 训练源 S 空间里 30 近邻均值减自身，按条件平均 |
| `learned_head` | no-JVP 学习头是独立开发扩展，不纳入此次 H1 六臂；`configs/w4_nojvp_head_development_v1.json` 仅用于 day4→5 的源半群体稳定性训练，不能据此直接解封新复制学习头。若进入复制，先另定完整配置，在当前 outer 训练源重训，不称为原版 GFG |
| `empirical_disp` | z̄_c,t − z̄_c,t−1，仅在有 t−1 时计算，两时间点都用当前折冻结的源变换；历史位移参照，不是理论上限 |

Uswap 报告供体 ID、匹配距离、供体复用率、U 深度保持误差。受体 U 总量为零时输出零 U；受体非零但没有正 U 总量的合法供体时该折失败并汇报，不静默丢弃 TF。该交换保留受体总 U 深度，测试的是状态匹配下 **U 基因组成** 的价值，不检验全部 U 信息，也不是精确条件随机化。

`direct_U_pool` 是维度/调参预算匹配的直接 U 基线，不是所有可能的 S+U 模型的上界。`vel_pool` 优于它只能支持当前表示/正则化下的动力学构造收益，不能说明确定性变换创造信息。`learned_head` 与 `empirical_disp` 的可执行配置/缺失情况在冻结前登记；不齐全不阻塞已确定的 H1 三臂，但必须标为未执行，不能补报为已完成。

## 5. 指标与统计

- **每个 TF 的误差**：L_arm,c = ‖ẑ_c,t+Δ − z̄_c,t+Δ‖²（50 维求和）。
- **每个 TF 的相对增益**：g_c = (L_ref,c − L_vel_pool,c) / max(L_static,c, 1e−12)。ref 为 `static`（比较一）或 `vel_pool_Uswap`（比较二）。分母下限固定为 PCA 坐标下 1e−12，并报告触发次数；补充报告未除分母的误差差，不按结果改主指标。
- **汇总**：对每个 TF，先在两个复制时间段上取平均，得到 ḡ_c；再对 TF 等权平均，得到 Ḡ。
- **区间**：对 TF 做 cluster bootstrap，10,000 次，随机 seed 固定为 20261017，取 95% 百分位区间。
- **检验**：对 ḡ_c 做单侧 Wilcoxon 符号秩检验，α=0.05（零差删除；全零时 p=1；固定实现版本并记录 ties/zero 个数）。H1 是两比较同时成立的交集判据，不从两者中挑较小的 p。小样本、TF 非随机抽样及共享训练折限制总体推广；bootstrap 单位是 TF，不是细胞、seed 或 TF×时间段。

### H1 成功标准（两个比较都要满足）

1. Ḡ 的 95% 区间下限 > 0；
2. Wilcoxon p < 0.05；
3. day2→3、day3→4 两个时间段各自的点估计都 > 0。

| H1 结果 | 结论写法 |
|---|---|
| 比较一、二都满足 | 本协议支持短时群体动力学特征增益，并优于源状态匹配的 U 组成交换；结合 H7 讨论 U 与变换各自贡献，不写因果证明 |
| 只有比较一满足 | 速度类特征有帮助，但不能归因于 U |
| 比较一不满足 | 短时群体速度增益不成立 |

### 次要假设

- **H2**：固定 day2 起点，使用同一组 TF 的 day2→3、day2→4、day2→5，在 Δ=1、2、3 天的相对 static 增益上拟合线性斜率，TF bootstrap 后平均斜率的 95% 区间上限 < 0 为成立。其他起点的相邻/跨时结果单列描述，不混入此斜率。衰减本身不能证明 U 特异性。
- **H3**：TF 配对差 g(2→3) − g(3→4) 的均值和 bootstrap 区间，区间下限 > 0 为成立。
- **H4**：同 H1 比较一的三条标准，状态流换成 foundation 编码器。编码器输入格式无法匹配时记为"未执行"。
- **H5**：追回比例 = (L_static − L_内含子速度) / (L_static − L_标记参照)，只在分母 > 0 时报告；分母 ≤0 记为不可定义，另报分子/分母及两种特征的 cos，不截断比例到 [0,1]。标记参照的检测效率/降解校准仅用时间 t 及以前可用数据或预先固定的外部参数；若依赖未来时间点拟合，必须另标 retrospective oracle，不能放入合法预测比较。5 个区间不足以支持高维预测器随意拟合：在读效应前补齐固定低维/滚动起点拟合规格，否则先仅报告同时间点动力学一致性。
- **H6**：同 H1、H2，单位换成细胞系，H1 在 4 个相邻时间段平均后按细胞系等权；H2 固定 3 小时起点，以跨度 log(3)、log(9)、log(21)、log(45) 拟合斜率。
- **H7**：逐 TF 报告 `direct_U_pool` 相对 `static`、`vel_pool` 相对 `direct_U_pool` 的误差差和相对增益，沿用 H1 的 seed 平均预测、TF 汇总和区间；只作辅助证据，不改变 H1 成败分类。

次要假设不做多重比较校正，结论写"支持/不支持"，不写"证明"。

## 7. 功效说明

RENGE 最终 QC 交集为 **16 个 TF**，并非最初粗估的 18–23。此前“标准化效应约 0.6 时功效约 0.8”只是未经本协议校准的粗估，不能当作已知功效。H1 同时要求两比较、两区间正方向及 CI/Wilcoxon 通过，须按完整判据做模拟，报告检出率及二项区间。W3 开发集的解析速度在 4 个 TF 上相对 static 平均降低约 2.3%，不能据此估计复制集效应或调节标准。

合成正对照与无预测增量零情形各至少 200 次：零情形采用可交换的群体 U 创新、独立的未来结果。W4-3 可先以固定独立训练/测试群体的功能 fixture 验证实现，其检出率/假阳性率不当作 RENGE 的功效。正式设计校准须另按最终 QC 的共同 TF 数、两区间配对和真实 outer LOTO/inner CV 执行，报告完整 H1 交集判据的检出率、假阳性率及跨区间相关假设；未执行时明确待完成。另做严格由观测 S 决定 U 的近邻交换压力测试；因为近邻并非精确同 S，交换可破坏已知函数关系，不能把“real 与 swap 必须无差异”当数学保证。合成校准异常先修实现或如实记录，不能查看复制集后调阈值。MDE 是在给定设计/假设下的检出能力；阴性结果能否排除某个效应，须看效应上置信限或预先设定的等效性检验，不能仅凭 80% 功效或 MDE 断言排除。
