## T1：超前-滞后检验的功效对照

**要回答的问题**：在 MeRLin Day0(310)→Day21(308)、313 个克隆的设置下，多强的"U 命运信号"能被测出来？现在的阴性（ALL p=0.909）算不算数？

**新脚本**：`scripts/phase0/w2_leadlag_power.py`，从 `leadlag_meclin.py` 复制数据加载、count-split、`knn_residual`、克隆均值等函数（不要 import 后改原文件）。

### T1.1 向量化 + 回归检查

- 把 `partial_corr_stat` 改成按基因的矩阵运算：对每个基因列，把 Y、X 对 C 做一元回归残差，再算列相关，最后对基因取均值。跳过标准差 < 1e-9 的列，规则和原函数一致。
- **回归检查**：同 seed 下复现原结果：ALL 的 obs = −0.0034、ε_S 对照 = +0.0047、null95 = +0.0042（容差 1e-4）。另外在 50 个随机基因上和原函数逐基因对比（容差 1e-6）。不通过就停止。

### T1.2 分别建零分布

原脚本的零分布只为 κ₀ 建了一份，ε_S 对照借用了它；而 ε_S 的 obs（+0.0047）其实高于 κ₀ 的 null95（+0.0042）。所以要给每个统计量**各自**做只打乱 Day21 克隆行的零分布，`n_perm=2000`，分别报告 p 值：

- κ₀（主统计量）
- ε_S(A) 对照：偏相关(S21, ε_S0 | S0)

### T1.3 正对照（检验流程本身能否检出东西）

聚合方式、零分布都和 T1.2 相同：

| 编号 | 统计量 | 预期 |
|---|---|---|
| P1 | 边际相关(S0_B, S21)，基因均值 | 必须显著，否则流程有问题 → **停止汇报** |
| P2 | 边际相关(ε_S0_A, S21)，不控制 S0 | 细粒度状态的持续性 |
| P3 | 偏相关(S21, ε_S0_A \| S0_B)，即 T1.2 的对照 | 已有，重算独立 p 值 |

### T1.4 克隆层信度

- **Day0 三路 count-split**：多项式稀疏化，每份 p=1/3，记为 A1、A2、B。
  - 在 A1、A2 上**各自**按原脚本流程做 PCA、kNN 残差，算出 κ（IV 的 b：A1 用 (A1, A2) 交叉估计，A2 反过来）。
  - S0 用 B。
- **Day21**：两路 count-split，得到 H1、H2。
- **克隆层每个基因的信度**：r_g = 跨克隆 corr(K_A1[:, g], K_A2[:, g])。用 Spearman–Brown 换算到检验实际用的深度（1/3 → 1/2，因子 1.5）：rel = 1.5r / (1 + 0.5r)。S21 同理（1/2 → 全深度，因子 2）。
- **报告**：
  - rel_κ、rel_ε_S、rel_S21 的中位数和四分位数，按模块（ALL / stress-like / neural-crest-like）分列；
  - κ 和 ε_S 的克隆间方差占比，即细胞层面的 ICC。

### T1.5 信号注入实验（核心）

目的：在噪声结构不变的前提下，往 κ₀ 里注入一个已知强度、与命运对齐的克隆成分，看检验多大概率能测出来。

1. Day21 两路 count-split 成 H1、H2。**注入用 H1，检验用 H2**，避免注入信号和检验共享同一份测量噪声，那样功效会偏乐观。
2. 在克隆层构造目标方向：T_g = 跨克隆标准化后的残差（S21_H1[:, g] 对 S0_B[:, g] 做一元回归后的残差）。
3. 对 usable 克隆 c 里的每个 Day0 细胞 i：κ₀′[i, g] = κ₀[i, g] + λ · sd_g · T_g[c]，其中 sd_g 是 κ₀ 在 usable 细胞上的细胞层标准差。其他细胞不变。
4. λ ∈ {0, 0.05, 0.1, 0.15, 0.2, 0.3, 0.5}。每个 λ 做 R=50 次重复，每次换 count-split 的 seed（Day0 的 A/B 和 Day21 的 H1/H2 都换）。每次重复用 500 次置换的零分布。
5. 检出定义有两个，分别报告：
   - (a) p < 0.05；
   - (b) p < 0.05 且 obs > ε_S 对照（原脚本的 pass 规则）。
6. 每个 λ 都要把效应量换算成：
   - 注入成分占细胞层方差的比例：ICC_inj ≈ λ² / (1 + λ²)；
   - 注入后克隆层 corr(K0′ 的克隆均值, T) 的实测值（跨基因中位数）。
7. **MDE** = 检出率 ≥ 80% 的最小 λ，同时给出对应的 ICC_inj 和克隆层相关。

性能：PCA/kNN 每个 seed 只做一次，注入和置换都是矩阵运算。如果 R=50 太慢，降到 R=20 并在 JSON 里注明。

### T1.6 判读（agent 只报数，结论由 Rinck 和我定，但请按这张表给出建议）

| 结果 | 含义 | 建议 |
|---|---|---|
| P1 不显著 | 流程本身有问题 | 停止，检查克隆匹配和 count-split |
| MDE 的 ICC_inj ≤ 0.02 | 检验很灵敏：连 ε_S 克隆结构五分之一强度的 U 信号都能测出 | 阴性算数，原命题在 MeRLin 上放下 |

**输出**：`outputs/w2_t1_leadlag_power.json`，以及检出率随 λ 变化的曲线（png，两种检出定义各一条线）。

## T2：打乱量纲审计（回答导师的问题）

**要回答的问题**：之前"局部打乱 U 后 GFG 速度几乎不变"，是因为 GFG 真的不读 U，还是因为打乱方式本身有问题？

**已知事实**（agent 先核对代码确认）：

- GFG 的输入是**原始计数**，只做了按基因的均值/方差标准化（`GFGDynamics.prepare`），**没有按细胞的文库大小归一化**。
- `probes.permute_local` 在原始 U 上打乱。分块规则是：同条件内、按 log2 深度分箱（箱内深度可差 2 倍）、只按 **z 的第 1 维**排序后每 10 个细胞一块。所以：
  - (i) 供体和受体细胞的 U 深度可能差到 2 倍，这就是量纲问题；
  - (ii) 只按 PC1 排序，块内细胞在其他维度上未必相邻，"局部"可能不局部。
- 而 A1 里的打乱是在**归一化后**的 U 上做的，只用来算 v_kin，**没有**把打乱后的 U 喂给 GFG。

**新脚本**：`scripts/phase0/w2_shuffle_scale_audit.py`。模型加载照抄 `a1_gfg_direction_source.py`，喂打乱原始 U 的方式参考 `calibrate_gfg_velocity_scale.py` / `run_velocity_stability_audit.py`。数据：RENGE 训练折，1200 个细胞，seed 0/1/2。

### T2.1 审计现有打乱

对 `permute_local` 移动过的每一对"受体 ← 供体"细胞，报告这几项的中位数和 5%/95% 分位数：

- U 总计数比；
- U/(U+S) 之差；
- 50 维 z 空间里的欧氏距离，以及它在受体细胞 10-NN 距离分布中的分位数。

### T2.2 喂给 GFG 的 U 变体（S 一律不动）

| 编号 | 变体 | 说明 |
|---|---|---|
| V0 | 真实 U | 基线 |
| V1 | 现有 `permute_local`（原始计数） | 复现旧结果 |
| V2 | V1 的供体关系 + 深度匹配 | u′_i = u_raw[d(i)] · (ΣU_i / ΣU_d(i))，即供体的组成、受体的深度 |
| V3 | 真局部 + 深度匹配 | 供体从全 z 空间的 10-NN 里随机抽（同条件），再按 V2 做深度匹配 |
| V4 | 全局打乱 + 深度匹配 | 同条件内随机供体，作为"最大破坏"的正对照 |
| V5 / V6 | U × 0.5 / U × 2 | 纯量纲敏感度 |
| V7 | U 置零 | 已有 `corrupt('zero_u')` |
| V8 | U 换成 10-NN 平均 | 平滑 |

**指标**（每个变体，相对 V0）：

- router 输入空间（PCA 速度 v）的 cos(v_GFG,V0, v_GFG,变体)：中位数、四分位数；
- 模长比 ‖v_变体‖ / ‖v_V0‖ 的中位数；
- 基因层面 vs 的 cos 中位数；
- 如果能复用已有代码：router 专家概率的平均总变差距离。

**校准参照（必须做）**：对每个变体，用同样的 U 变体算 **v_kin**（`a1` 里的 u − γs 公式），报告 cos(v_kin,V0, v_kin,变体)。v_kin 按定义是读 U 的，它告诉我们一个读 U 的估计器在每种打乱下"应该"变多少。

### T2.3 判读

| 观察 | 含义 |
|---|---|
| V4 下 GFG 的 cos ≥ 0.9，而 v_kin 的 cos 明显更低 | GFG 确实不读 U，和量纲无关 → 导师的量纲担忧可以排除，A1 结论成立 |
| V3 下 v_kin 自己的 cos 也 ≥ 0.9 | 局部打乱本身没有功效（邻居的 U 本来就像，准稳态 u≈α/β）→ "局部打乱后不变"不能作为任何估计器"不读 U"的证据，以后只用 V4 类检验 |
| V1 和 V2 差别大 | 旧结果被深度不匹配污染，A1/meeting 里的数要重跑 |
| V5/V6 变化大、V2–V4 变化小 | GFG 只对 U 的总量敏感，不读组成 |

**输出**：`outputs/w2_t2_shuffle_scale_audit.json`，加一张"变体 × {GFG, v_kin}"的 cos 热图。

## T3：ΔU 信度与条件层超前-滞后（决定"U 作为监督目标"这条线开不开）

**思路**：之前的阴性结果是"逐细胞速度作为**输入**"没有增益。新线是把每个扰动的 pseudobulk ΔU 当作额外的**监督目标**（多一个测量到的响应通道，偏向直接的转录响应）。前提是 ΔU 在 pseudobulk 层面可靠，并且含有 ΔS 之外的成分。

**新脚本**：`scripts/phase0/w2_deltaU_reliability.py`。数据：RENGE day4 和 day5 细胞 × 基因的原始 U/S 加 TF 标签（只用 14 个训练 + 4 个 validation TF，以及非靶向对照，如果有的话）。基因：2000 个固定 HVG。

### T3.1 Pseudobulk 与参照

- 每个条件 c、每天 d：先把细胞的计数加总，再 CPM + log1p。
- Δ_c,d = pb(c, d) − pb(参照, d)。
  - 参照优先用同一天的非靶向对照；
  - 没有对照时，用同一天其他训练条件的留一均值，并在 JSON 里写明用的是哪种。
- 单独记录每个条件每天的细胞数。

### T3.2 信度

- 细胞层 count-split 成三份，各 p=1/3：
  - 第 C 份只用来挑"响应基因"：每个条件 |ΔS| 最大的 200 个；
  - A、B 两份用来算信度，避免挑基因带来的偏差。
- 每个条件、每天：跨基因 corr(ΔU^A, ΔU^B)，再做 Spearman–Brown（因子 2），全部 2000 个基因和响应基因各算一遍。ΔS 同样算。
- **ΔS 之外的独立成分**：η_c = ΔU − b·ΔS，其中 b 用 IV 估计（每个条件跨基因）：b = cov(ΔU^B, ΔS^A) / cov(ΔS^B, ΔS^A)。用固定的 b 算 η 的 A/B 信度。

### T3.3 条件层超前-滞后

对每个条件，跨基因计算偏相关(ΔS_c,day5, ΔU_c,day4[A] | ΔS_c,day4[B])，再对条件取均值。

- **零分布**：只打乱 day5 的条件配对（c ↔ c′，不允许配回自己），2000 次。
- **对照**：把 ΔU_day4[A] 换成 ΔS_day4[A]，衡量"同一个 ΔS 再测一次"能带来多少。
- **防止同日耦合**：day4 的 ΔU 和 ΔS 必须来自不同的 count-split 半份，和 T1 的修正一致。

### T3.4 判读（B 线 GPU 实验的门槛）

| 结果 | 决定 |
|---|---|
| 响应基因上 ΔU 信度中位数 ≥ 0.5，**且** η 信度 ≥ 0.3，**且** T3.3 的 p < 0.05 并高于 ΔS 对照 | 通过 → 下周用 1 张 GPU 跑"ΔU 辅助损失"实验 |
| 前两条过、第三条不过 | 有条件通过：ΔU 是可靠的额外读出，但不提前预示；辅助损失实验仍可小规模试 |
| ΔU 信度 < 0.3 | 关闭 B 线 |

参考：RENGE 在细胞层面的 ε_U 信度只有 0.077。pseudobulk 聚合了几百个细胞，预期会高很多，这正是要测的。

**输出**：`outputs/w2_t3_deltaU_reliability.json`（每个条件一行）。
