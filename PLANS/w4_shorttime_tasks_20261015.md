## 0. 背景与主张

项目主线改为短时线（Rinck 2026-10-14 决定）。要检验的主张：

> 扰动后的短时间内，群体层面的 RNA 速度（由 U、S 计算）能提前预示 S 的下一步变化，比只用当前 S 更准；而且增益随预测跨度变长而衰减。

和原命题的区别：
- 不再讲逐细胞或逐克隆的命运；
- 只讲扰动群体、几小时到一天的预测。

这是更直接可检验的群体预测设定，但不是无需假设即可识别真实动力学的区域。非配对终点边际通常不能唯一确定逐细胞耦合/向量场；U/S 动力学约束可能提供额外信息，需单独检验，不能从置换不变损失推出所有逐细胞速度都不可能识别。

架构采用**双流**：
- 状态流只吃 S；
- 速度流吃 U+S，使用简单动力学速度 v = u − γ_g·s；
- 速度通过状态映射的雅可比投影到状态坐标。

不使用 GFG 解码器 JVP；不使用 MouseBrain seed0 权重。

2026-10-17 用户批准的架构范围：当前六臂复制保持解析速度 + 群体 ridge，不因新增模块而延后或替换主检验。轻量 no-JVP 动力学学习头作为后续升级；旧 router/专家代码保留，但不进入 W4 的训练、调参和成功判据。先检验局部群体动力学的额外收益，再按独立协议决定是否启用 router；不把当前群体均值改善称为路由阳性。完整模块身份及阶段门见 `PLANS/w5_w8_roadmap_20261017.md` 第 0.1 节。本条不冻结新增学习头/router 科学配置，也不变更 W4 预注册。

## W4-3 双流短时框架

**脚本**：`scripts/phase0/w4_shorttime.py`（主程序）、`w4_streams.py`（两条流）、`w4_arms.py`（对照臂）。可以复用 `w3_validation.py` 里已校准的组件（U-only 打乱、统一 log-PCA 导数），但要在新脚本里显式调用，不改原文件。

### 数据流（每个时间段 t→t+Δ，每个留一 TF 折）

1. **源变换拟合（只用时间 t 的源细胞，排除留出 TF）**：用全部对齐基因的 S 文库因子归一 S/U 后选 2000 个 HVG；拟合 log1p S 的 PCA-50、γ_g（S 的下 5% 与上 5% 尾部合并 OLS；`fit_gamma_tail` 实际为双尾，不是仅上尾）和 k-means。随后冻结。时间 t+Δ 的任何数据都不参与这些源变换的拟合；但**训练 TF 的未来目标用于监督 response ridge 是合法的**。当前旧 fold 的 PCA 曾用 source+训练 target 拟合，W4 必须从 raw source 重建，不能沿用旧 PCA。
2. **状态流（只吃 S）**：每个细胞 z_i = PCA(log1p(s_i / 文库因子 × 1e4))。
3. **速度流（吃 U+S）**：每个细胞每个基因 v_ig = u_ig − γ_g·s_ig，U 用同一个 S 文库因子归一化。
4. **投影**：ż_i = W · (v_i / (1 + s_i))。W 是 PCA 载荷，s_i 是归一化后的 S，求导时固定源侧文库因子。β=1 的速度单位是相对量，不声称为每小时/每天的实际速度；跨度尺度由训练 TF 的 A 校准。
5. **群体聚合**（每个条件 c、时间 t）：
   - z̄_c：状态均值；
   - **主**：v̄_c^pool，先合并条件 c 的 **raw U/S**，以全部基因 pooled S 总量将二者规范化到 1e4，取 HVG，再按第 3、4 步计算（在 s_pool 上求导）；
   - 对照：v̄_c^mean，逐细胞 ż_i 的平均；
   - 次要：按状态簇（在训练源上用 k-means 拟合 k=8，冻结）分层的群体速度。
6. **预测器**：ẑ_c,t+Δ = z̄_c,t + A·v̄_c,t + B·[z̄_c,t, e_c] + b。训练样本为训练 TF 和对照的源特征/未来目标；α 从 {0.1, 1, 10, 100, 1000} 中按内层留一训练 TF 的均值误差选择，平局选较大 α。所有输入块的 StandardScaler 仅拟合当前 inner 训练条件，最终在 outer 训练条件重拟合。源变换在 outer 训练源上拟合一次供内层 CV 共用，属于已声明的无监督源信息。e_c 默认现有 ESM2 嵌入。
7. **目标和指标**：时间 t+Δ 留出 TF 的真实状态均值 z̄_c,t+Δ。坐标用第 1 步冻结的 PCA，对时间 t+Δ 的 S 做同样的归一化和 log1p。指标是 TF 等权的平方误差。

**对照条件**：AAVS1/CTRL 不在 TF 的 ESM 词表时，统一用全零空扰动编码，所有臂一致；TF 缺 ESM 必须报错。对照只作为训练辅助，源/目标各 ≥1 个合格细胞即可纳入，不受独立 TF 的 ≥50 门槛限制，也不计入 TF 样本量。

**量的区别**：目标始终是 mean(log1p S) 的 PCA 状态。raw pool 引入深度权重，且 log1p 非线性，因此 `vel_pool` 是有待验证的群体特征，不宣称是该质心的精确导数；`vel_mean` 才是固定源归一因子下逐细胞导数的平均。

### 对照臂（每个臂的超参数选择预算相同）

| 臂 | 预测器的速度输入 |
|---|---|
| `static` | 无（去掉 A 项） |
| `vel_pool` | v̄_c^pool（**主臂**） |
| `vel_mean` | v̄_c^mean |
| `direct_U_pool` | W·log1p(u_pool)，与主臂同一训练源 S PCA 载荷，不减 PCA 均值；50 维直接 U 基线，输入状态/ESM、ridge 网格和调参预算同主臂 |
| `vel_pool_Uswap` | 从当前 outer 训练源条件中选源 S 均值最近且不同于受体的供体；借其 raw pooled U 组成、匹配受体 raw U 总量，再用受体 S 文库因子规范化；S 不动。报告距离/供体复用/深度，零深度规则见预注册 |
| `pseudo_S` | 只用 S 推出的伪速度：每个细胞在训练源 S 空间里 30 近邻的均值减自身，再按条件平均。维度和 v̄ 相同 |
| `learned_head` | no-JVP 学习版速度头（冻结 innovation），当前训练源重训，次要待实现；不称为原版 GFG，不沿用读过目标的权重 |
| `empirical_disp` | z̄_c,t − z̄_c,t−1（只在存在 t−1 时）：用同一冻结变换计算，历史位移参照，不是理论上限 |

`direct_U_pool` 增加 H7 辅助比较，不改变 H1 两个主比较的交集判据。Uswap 是组成匹配压力对照，不是精确条件随机化；直接 U 基线是当前压缩表示/预算匹配的基线，不是任意 S+U 模型上界。

### 单元测试（必须全部通过才能运行 W4-4）

1. 固定源文库归一因子，投影的解析导数和有限差分一致（相对误差 < 1e-4）。
2. 没有 log 变换且文库大小相同（或显式使用相同深度权重）时，先合并再算和逐细胞聚合一致；一般不同文库大小下不强设相等。
3. 泄漏检查：改变任意 t+Δ 数据，**源变换**哈希不变；改变当前 outer 留出目标，所有该折训练产物和预测不变；改变训练 TF 的未来目标应允许 response ridge 改变。不同折的标签角色分开审计。
4. `vel_pool_Uswap` 前后 S 完全不变，U 的总量匹配受体。
5. 合成正对照：构造 U 创新预测下一时刻的模拟，报告主臂相对 static/Uswap 的完整 H1 检出率；零情形让可交换的群体 U 创新与未来结果独立，报告完整 H1 假阳性率。各至少 200 次，附二项区间。U=f(S) 近邻交换另作压力测试，近邻非同状态不能保证零差异。异常先查实现/报告局限，不调真实复制集标准来追求通过。
6. 检查四个 seed 先平均预测再算指标，TF 而非 seed/细胞定义重采样单位；检查 `direct_U_pool` 与主臂额外输入维度和 ridge 搜索次数一致。
