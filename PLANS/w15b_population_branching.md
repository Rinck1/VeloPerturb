## 0. 要回答的问题

> 动力学信息能否预测一个细胞群体在 t+Δ 时**以什么比例分到各个分支**？

**理论依据**：router 模型的预测分布是混合分布 Σ_k π_k · P_k，π_k = 群体内全部源细胞分给专家 k 的平均权重。
- 逐细胞权重 q_i 不可识别（N1：群体内置换不改变目标函数）；
- 群体权重 π 在各成分终点可区分时可识别（有限混合模型权重的可识别性）。
所以"分支比例"是 router 结构中可识别的部分。

**已有旁证（仓库现有路由记录，r4 开发集）**：三个起点时间之间路由总量 π 的平均总变差，真实速度 router 为 0.138 / 0.144 / 0.198（b1-36k / b0-36k / K8-12k），静态 router 为 0.091 / 0.090 / 0.107，打乱速度为 0.077 / 0.074 / —。读真实动力学的 router，群体分配随时间变化更大。这只是旁证：专家未对应生物学分支，且只有 3 个起点。

**明确不检验**：哪个源细胞走向哪个分支（逐细胞命运）。唯一例外是 BR-3b 的谱系检查，它有克隆条形码作为外部依据，并标为探索性。

## BR-1 描述性检查：真实数据里分支比例变了多少（CPU，半天）

**不涉及任何模型。**

对每个相邻时间窗（sci-FATE2：r4 的 05→10、10→15、15→20h，r1–r3 的 D3→4 … D7→8；LARRY：day2→4、day4→6）：
1. 计算起点与终点的分支比例，以及二者的总变差 TV_obs；
2. 细胞层面 bootstrap 1,000 次，得到"同一时间点重复抽样"造成的 TV 噪声水平 TV_noise（取 95% 分位）；
3. 若 TV_obs ≤ 2 × TV_noise，该窗口标记为"无可检出的分岔信号"。

**门槛 G-BR1**：至少有 3 个时间窗被判为"有分岔信号"，才进入 BR-2 的正式比较；否则汇报，分岔任务降为解释性分析。

额外报告：每个分支比例变化与细胞周期评分（标准 S/G2M 基因集，打分方法写明）的关系，用于提示增殖或死亡的混杂。只描述，不校正。

## BR-2 回溯分析：现有冻结模型的分支比例误差（CPU，1 天；不重训）

**输入**：已冻结的预测，不新训练任何模型。
- r4：W10 b0/36k、W13 b1/36k 的 static、velocity、shuffled 三臂三 seed（每个源细胞的 K 个候选终点与 q）；
- W14 留一重复：待 W14 主评分完成后，用其冻结预测追加同样分析。

**预测的分支比例**：p̂_b = (1/N) Σ_i Σ_k q_ik · 1[分类器(候选终点_ik) = b]，三 seed 等权混合。

**对比基线**（全部在冻结前写定，不按结果增删）：

| 基线 | 定义 |
|---|---|
| 不变 | p̂ = 起点的分支比例 |
| 线性外推 | 用前两个时间点的比例线性外推到 t+Δ，截断到 [0,1] 后归一化；只在有前两个时间点时定义 |
| static router | 同上公式，用 static 臂的预测 |
| 打乱速度 router | 同上公式，用 shuffled 臂的预测 |
| CellRank 平均命运概率 | 用 scVelo 随机模型速度构建 CellRank 速度核（默认参数，写入配置），对源群体的终末状态吸收概率取平均。注意它表示"最终命运"而非"t+Δ 时的比例"，二者时间含义不同，只作描述性对照，不进入门槛 |

**指标**：预测与观测分支比例的总变差 TV(p̂, p_obs)；另报告每个分支的绝对误差。

**专家—分支对应**：对每个专家，报告其候选终点的分支构成（最大类占比 = 纯度），以及各专家的群体权重随时间的变化。只描述，**不得**据此把专家命名为某个生物分支。

**门槛 G-BR2**：在"有分岔信号"的窗口中，真实速度 router 的 TV 误差同时低于"不变"、static、shuffled，且这样的窗口占一半以上。这是开发数据上的描述性门槛，不是显著性检验。

## BR-3 分支监督原型（GPU，2 天；只在开发数据上）

只有 G-BR1、G-BR2 都通过才执行。

### BR-3a 在小模型（L1）上加群体分支损失

- 专家数 K = 分支数 B（"未分化"或无明确去向的细胞单独算一类）；
- 总损失 = 原 W13 b1 损失 + λ_br · KL(p_obs^{t+Δ} ‖ p̂^{t+Δ})，其中：
  - p_obs 只来自**训练转移**的观测目标分支比例（群体层面的观测，不需要逐细胞标签）；
  - p̂_b = (1/N) Σ_i Σ_k q_ik · c_b(候选终点_ik)，c 为冻结的**软**分类器（kNN 的类别频率），保证可微；
- λ_br 固定为 0.1，另报告 1.0 作为敏感性，不按结果选择；
- 臂：static、velocity、shuffled，结构相同，三 seed，训练步数与 b1 相同；
- 评估：r4 开发窗口上的能量距离与分支比例 TV，两者都报告。

**数学说明（写进汇报）**：分支损失只约束群体层面的比例，而群体比例是可识别量；它不提供任何逐细胞监督，因此不违反 N1。软分类器冻结，梯度只流向 router 与专家。

### BR-3b LARRY 谱系检查（探索性）

LARRY 有克隆条形码，可以检查"源群体的哪一部分走向哪个分支"，这是其他数据上无法验证的：
1. 在 LARRY 上按 BR-3a 训练（训练划分：按克隆随机分成训练 / 留出 80/20，seed 0，同一克隆的细胞只在一侧）；
2. 对留出克隆，把它在 day2 的细胞作为一个小群体，用模型预测其 day4 的分支比例；
3. 与该克隆在 day4 的实际分支比例比较；对照：static、shuffled、"不变"基线。

**已知风险，预先写明**：W1 在 LARRY day2 上的克隆级 κ 检验未通过（p=0.61），且 day2→4 间隔 48 小时，远超 U 的信息时间尺度。此检查预期较低，结果无论正负都只作探索性报告。
