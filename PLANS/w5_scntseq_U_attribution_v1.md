# scNT-seq U 总量、组成与文库权重归因

日期：2026-10-17。状态：探索性固定设计，运行前记录。

## 问题

修复 v2 的预定候选在两个区间均优于 identity，但去掉 −γS 的 U 驱动项同样有效，保留 U 总量、替换为基线 U 基因组成也有预测力。本实验区分这种增量依赖总量还是基因组成，以及是否依赖深文库细胞的群体权重。不改变 v1、v2 的结果或主判据，不筛选新的最佳模型。

## 固定设计

- 沿用 0 分钟拟合的 HVG/PCA 与 v2 正则 γ，不重新选择基因或 γ。
- 沿用 15→30 分钟的一次性两参数读出、ridge=1 和 decay 时间核。不使用 60/120 分钟训练读出。
- 所有模型的 S 状态列、预测起点、评价目标相同，均为原始全群体的平均 log-S PCA；仅改变动力学列。
- U 因子为 2×2：当前/基线基因组成 × 当前/基线 U/S 总量比。使用全基因 U/S 总量，不用 HVG 总量代替。基线组成使用 0 分钟；两因子在 0 分钟均不改变原始 U。
- 两种聚合：原始 count pooling（按 S 文库大小隐含加权）；逐细胞 S 归一化后取均值（等细胞权重）。后一种保留每个细胞的 U/S 比，去掉跨细胞的 S 深度权重，不是分别归一化 S 与 U。
- 两种动力学列：完整基线中心化 U−γS（第二列系数非负）；仅 U 导数差（第二列允许有符号，与已报告机制对照一致）。共 16 个因子臂。
- 另报告两种聚合的非线性 S-only 控制，以及原 v2 候选与 identity。全部 20 臂报告，不改变原候选身份。
- 先冻结 30→60 预测，再读 60 分钟作为第二次预测源；120 分钟只在独立评价步骤读取。

## 解释规则

- “固定总量”保留当前 U 基因组成，却移除群体 U/S 总量变化；不是技术无损操作。
- “基线组成”保留当前 U/S 总量，却移除当前逐基因 U 组成。该特征仍通过当前 S 的 log 导数分母发生基因依赖。
- 等细胞聚合与原 pooling 的差异检验文库权重敏感性，不等同于证明测序深度伪影：RNA 含量、捕获率与细胞状态可能同时改变文库大小。
- 单刺激系列无 spike-in/独立重复，不能仅凭这些对照区分全局转录生物学与技术 U/S 比变化。不生成生物学 p 值。
- 评价用两个区间的 MSE 和相对 identity 增益，报告所有因子，不启用 router。
