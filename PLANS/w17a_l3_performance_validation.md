## 0. 要回答的问题

Traxler 6→24h 上，L3（CellFlow 主干 + 固定源侧 router + K8 独立专家 ODE，约 39 万参数）比参数匹配的原生 CellFlow（L2）能量距离低约 33%，21/21 个"KO × seed"配对改善，与是否加 velocity 无关（32.7% / 33.0%）。

这个数字来自 7 个开发 KO、单次切分，L2 只按参数量选宽度、没有在 Traxler 上调参。本轮回答：

1. 给 L2 与 L3 **相同的调参预算**之后，差距还在不在；
2. 在 **63 个开发 KO 的三折交叉验证**上，差距是否稳定；
3. 在 **RENGE、sci-FATE2** 上方向是否一致；
4. 相对**简单基线**和**外部方法**处在什么位置；
5. **U 的贡献**：只用 S、S 与 U 合并、S 与 U 分开，三者差多少。

本轮**不**做任何新的 velocity 变体。

## 3. A1 公平调参（GPU，1–2 天）

**目的**：排除"L2 没调好"。

- 数据：Traxler 6→24h，W16A 的 fold0 训练 KO（42 个）内部再做 3 折内层交叉验证。**不使用 fold0 的留出 KO 选参**。
- 两个模型各 8 个配置，预算相同：
  - L2（原生 CellFlow）：宽度 {256, 512}、学习率 {1e-4, 3e-4}、步数 {5000, 15000}；另加 1 个 CellFlow 官方默认配置（不足 8 个时）；
  - L3：同样的宽度、学习率、步数网格（K=8 不变）；
- 每个配置 2 个 seed。选择标准：内层交叉验证的平均能量距离，同分取参数更少者；
- 选定后写入 `configs/w17a_selected_v1.json` 并冻结，提交号记入第 9 节。此后 A2–A5 一律使用选定配置，不再调整。

## 4. A2 三折交叉验证（GPU，1 天）

- 数据：W16A 的同一套 63 KO 三折（每折 42 训练 / 21 留出）；
- 臂：选定配置的 L2 与 L3，均使用 S50 + U50 + ESM + 生物学时间，不加 velocity；
- 每折 3 个 seed；
- 主比较：L3 相对 L2 的配对能量距离改善，先 seed 平均，再 63 个 KO 等权；10,000 次 KO 级 bootstrap 区间；报告改善的 KO 数；
- **预先写定的判读**：
  - 改善均值 ≥ 10%、区间下界 > 0、三个 seed 汇总均为正，且 A0 中 RENGE 方向一致：记为"结构优势稳定"，进入外部基线比较与最终预注册；
  - 改善为正但 < 10% 或区间跨 0：记为"结构优势存在但较小"；
  - 改善 ≤ 0：记为"33% 未复现"，主线改为分析型定位。

0→6h 任务作为次要比较，同样三折、同样臂，结果单列。

## 5. A3 基线与外部方法（GPU，2–3 天；A2 判为"稳定"或"较小"时执行）

同一三折、同一评分，每个方法使用相同的调参预算（各 8 个配置，内层交叉验证选择；简单基线无参数则不调）。

| 方法 | 说明 |
|---|---|
| 原样不动 | 预测 = 6h 源细胞本身 |
| 均值平移 | 源细胞 + 训练 KO 的平均位移 |
| 线性条件平移 | 源细胞 + 由 ESM 嵌入线性回归预测的 KO 特异位移（ridge，α 内层选择） |
| CellFlow 官方默认 | 不改任何默认超参数 |
| scDFM | 源分布设为 6h 细胞，条件为 ESM；适配方式写入第 9 节 |
| State（State Transition） | 从头训练（不使用 Arc 预训练权重，避免数据泄漏争议），输入为 6h 细胞集合 + ESM；若许可或实现不可行，记录原因 |

外部方法的适配代码与所有改动完整记录，任何一处无法公平适配都在报告中写明，不静默省略。

## 7. A5 评估指标（全部比较统一使用）

| 指标 | 说明 |
|---|---|
| 能量距离（主指标） | 现有实现：PCA-50，除以 √50，512/512 细胞，三 seed 混合 |
| MMD | RBF 核，带宽用训练目标细胞两两距离中位数固定 |
| 均值 MSE | PCA-50 群体均值 |
| 扰动效应相关 | 只用训练 KO 定义的 top-200 响应基因；预测与真实的（24h − 6h）均值变化的 Pearson 相关 |
| 方向一致率 | 上述基因中，预测与真实变化方向一致的比例 |
| 模式比例 TV | 训练目标 k-means（k=8）冻结后，预测与真实簇比例的总变差 |

所有指标都报告，主判读只看能量距离；其他指标与主指标方向不一致时如实写出。
