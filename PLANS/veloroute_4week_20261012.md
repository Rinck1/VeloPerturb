## A 线：诊断总开关

三个诊断都不需要训练模型，W1 内出结果，决定后续线是否值得做。

### A1 GFG 速度方向来源（N4 诊断）

问题：当前 GFG 速度方向来自 U/S 动力学，还是密度几何？

1. 冻结 checkpoint（a9d9…）对 RENGE day4 训练源 1,200 细胞推理，得 PCA-50 中 v_GFG。
2. mean-shift 向量：mᵢ =（20 近邻 PCA-50 均值）− zᵢ。
3. 动力学速度：训练折按基因拟合稳态 γ_g（u 对 s 上下 5% 分位回归），v_kin = u − γ_g·s，原始归一化计数、不平滑，经同一 PCA 旋转。
4. 报告每细胞 cos(v_GFG, m)、cos(v_GFG, v_kin)、cos(v_kin, m) 的中位数与 IQR。

判据：cos(v_GFG, m) − cos(v_GFG, v_kin) ≥ 0.2 → N4 成立，下游不再用当前 GFG，D 线必做。

### A2 U 创新项信度 + 克隆 ICC（总开关）

问题：单细胞 U 偏差是可重复信号，还是计数噪声？同克隆间是否相似？

1. 对 MeRLin 315、310、RENGE day4 整数 U/S 做二项 count-split（p=0.5），得 A、B 两半。
2. 每半：z = S 的 PCA-50；E[U|z] 用 k=30 kNN 回归；ε = log1p(U) − E[U|z]，全程不平滑。
3. ε 汇总到模块级：A 半拟合的前 20 主成分；MeRLin 另算 5 个 DTP 程序基因集均值。
4. 信度：A、B 两半同一细胞模块分数的相关，Spearman–Brown 校正。
5. 克隆 ICC（仅 MeRLin）：只取 ≥2 细胞克隆。零分布 = z 十分位分层内打乱克隆标签、保持克隆大小，1,000 次。正对照：z 的 ICC。

判据：校正信度 ≥ 0.2 且 ICC 95% 下界 > 零分布 95 分位 → 继续。信度 < 0.1 → 停止一切逐细胞主张，B2 只作保底证据。

### A3 旋度 η

问题：速度场是否有非平衡环流？这是 velocity 相对快照唯一不可替代的部分。

1. 数据：pancreas、bonemarrow、dentate、MeRLin 315。速度用 v_kin（scVelo stochastic，不用 GFG）。
2. 先回归掉 S/G2M 细胞周期分数，或剔除细胞周期基因。
3. PCA-20 中，每细胞 k=100 邻域局部线性回归 v ≈ Ĵ(z−z̄)+b，同邻域算协方差 Σ。
4. η = ‖ĴΣ−(ĴΣ)ᵀ‖ / (2‖ĴΣ‖)（Frobenius），取中位数。
5. 三个零分布：count-split 两半 η 差；γ 随机重标（每基因 ×[0.5,2]）；mean-shift 伪速度 η。

判据：至少 2 个数据集 η 高于三个零分布 95 分位 → "快照×速度互补可识别"进主线；否则只进保底论文。

## B 线：多分叉（LARRY）

### B1 LARRY 数据获取与 U/S 核实

1. 下载 figshare `larry_invitro_adata_sub_raw.h5ad`，检查 layers 有无 spliced/unspliced，报告每细胞 U 中位数。
2. 无 U/S 时：从 GEO GSE140802 下载原始 FASTQ（inDrops），用 simpleaf/alevin-fry 按自定义化学几何定量。
3. 时间盒 5 天，超时止损。

判据：每细胞 U 中位数 ≥ 300 → B2 逐细胞+场级两层；<300 → B2 只做场级。

### B2 LARRY 克隆命运检验

- 取有 day4/6 后代的克隆里的 day2 细胞。克隆命运偏向 = 后代 Neu/(Neu+Mono) 比例，按 Weinreb 2020 二值化。
- 四臂同一分类器（岭回归 logistic；LightGBM 稳健性）：(1) z-only（S PCA-50）；(2) z+ε_U 模块分数；(3) z+置换 ε_U（z 匹配块内置换）；(4) z+场级速度 E[v_kin|z]。
- 评估：按克隆分组 5 折 CV，重复 10 次；AUROC + 偏向比例 Spearman；克隆 bootstrap 2,000。

判据：臂 2 相对臂 1 ΔAUROC ≥ 0.02、95% 区间不含 0，且臂 2 > 臂 3 → 多分叉主线成立。通过后 W3 补 WOT、CellRank。

## C 线：追 SOTA（动力学调控先验）

核心假设：U 读出每个基因此刻的转录速率，用它回归调控因子表达得到有向调控关系，比对称共表达更能预测敲低效应。velocity 只在训练时作先验。

### C1 RENGE 有向调控快测

前提：RENGE 有非靶向对照细胞。

1. 只用对照细胞（day4+day5），按 S 的 PCA 做 metacell（每约 30 细胞）。
2. 转录速率代理 α̂_g = U_g（metacell 归一化）。对每个靶 g，岭回归 α̂_g ~ S_r，r = 23 TF + 前 500 HVG，排除 g 自身 → 有向矩阵 W。
3. 共表达基线：S_g ~ S_r → 矩阵 C。
4. 每 TF r：观测 Δ_r = KO r vs 对照 day5 伪 bulk log 差；预测 Δ̂_dir = W[:,r]·ΔS_r，Δ̂_cov = C[:,r]·ΔS_r。
5. 指标：每 TF 在 top-200 DEG 上的 Pearson(Δ̂, Δ)，排除 r 自身。

判据：有向优于共表达 TF ≥ 15/23 且配对 Wilcoxon p<0.05 → 方向信号成立。弱信号也值得进 C3。

### C2 Norman 2019 下载与 U/S 定量

1. GEO GSE133344 原始 FASTQ（10x v2 3'，K562 CRISPRa 单/双扰动）后台多连接下载。
2. W2 用 simpleaf USA 定量 S/U/A；报告对照细胞 U 中位数。
3. 备选：Replogle RPE1 essential。

判据：W2 结束未完成 → C3 改在 RENGE 上做。

### C3 线性基线 + 四种基因嵌入

框架 Ahlmann-Eltze 线性基线（Y ≈ G·W·Pᵀ+b），替换基因嵌入 G：
- (a) 共表达 PCA（S 对 S）
- (b) 对照细胞有向回归（U 对 S），"调控者"和"靶基因"两套非对称嵌入
- (c) 训练扰动数据学到的嵌入（原文最强）
- (d) (b) 拼 (c)；D3 后加 (b') 动力学版 GFG 嵌入

评估：留出未见单扰动/组合；Pearson-delta（top-20、top-1000）+ 扰动区分度；扰动 bootstrap。

判据：(b)>(a) 且 (d)>(c)，区间不含 0 → 追 SOTA 主线成立。

## D 线：动力学版 GFG

### D1 实现

保留：双编码器、两码本、解码器 JVP 切向投影、逐基因 token 与基因间注意力。
改动：新增基因级共享 β_g、γ_g（对数参数化）；动力学损失 ‖v_s,tan − (β·u−γ·s)‖² 按计数噪声加权；删对齐损失，平滑权重 300→≤1；输入原始计数，NB 似然重构；速度编码器额外输入 U 创新项 u−E[u|s]；VQ 软分配，监控码本使用率与互信息。
单元测试：JVP = 有限差分；合成局部打乱 U 后方向必须改变。

### D2 训练与验收

pancreas + MouseBrain 训练。四项验收全过才供下游：
1. 局部打乱 U 后方向 cos 中位 ≤ 0.9（现 GFG 0.9998）。
2. cos(v, v_kin) > cos(v, mean-shift)。
3. count-split 两半方向 cos ≥ 0.8。
4. CBDir、ICCoh 仅参考。

判据：未通过 → 下游改用 v_kin（scVelo），GFG 退出主线。

### D3 语料预训练 → 有向基因嵌入

前提：D2 通过且 C1 有方向信号。Velocyto 语料 GPU 0–3 DDP 预训练（先 500 文件），导出"调控者/靶基因"嵌入作 C3 的 (b')。
判据：(b') > (b) → "动力学先验基础模型"成为卖点。

## E 线：保底证据

证明"为什么之前 20 项对照测不出结果"。

### E1 置换设计实证（保底论文核心图）

1. RENGE：岭回归从 (z,v) 预测 day5 伪 bulk。
2. 对比条件内 z 匹配置换（理论恒 0）vs 跨条件 z 匹配置换。

判据：前者 ≈0 → 验证零假设设计定理；后者区间不跨零 → "群体层面 velocity 信号"成立。

### E2 合成降级阶梯（规格由 @Rinck 提供）

三吸引子系统，可调旋度 ω、γ 异质性、U 深度（115–3,120）、逐细胞 S×U 信号强度（100%→1%）。比较仅快照/仅速度/联合的分支比例误差 Δπ。用 A3 的 η 和 A2 的信度标出真实数据档位。
判据：ω>0 时联合误差 ≤ 仅快照一半，ω=0 持平 → 理论图成立。

### E3 +0.022 复核（可选）

1. RENGE 背景减法重跑 3 seed。
2. 加两臂：协方差匹配高斯噪声臂、跨条件互换臂。
判据：高斯噪声臂也有同等增益 → 是分散度效应，撤回该正结果。
