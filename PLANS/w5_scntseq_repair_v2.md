# scNT-seq 修复版 v2：估计、背景与有限预测视野

2026-10-17。用户授权“解决问题”。本配置在 v2 运行前写定；原系列时点已经看过，全部 v2 数字属于探索开发，不改 v1 的未通过结果。配置为 `configs/w5_scntseq_repair_v2.json`。不调用原版 GFG/JVP，不训练 router。

## 固定修复

1. 保留 v1 仅在0分钟拟合的 HVG/PCA/源归一化。对比旧 tail γ 与正则群体 γ：先合并0分钟 raw S/U，以全基因 pooled S 深度归一到1e4。令 g0=ΣU_HVG/ΣS_HVG，`γ_g=(U_g + λg0)/(S_g + λ)`，λ=1个归一化 S 单位。该正先验借用群体信息，避免“尾部 U/S 未共现”被直接当作零斜率；不是测得了291个从未观测到基线 U 的基因的真实降解率。
2. 对比 raw 与 baseline0 中心化场：后者逐源群体计算 `v_t−v_0`，同一估计器/同一聚合口径相减，不让未来目标参与基线。
3. 每种表示用15→30分钟学习固定低维读出，列范数只由校准源特征确定；固定 ridge=1，不搜超参。速度系数非负，S/U/新生 RNA 通用特征系数可正可负，避免对 U 强加动力学方向限制。`state_velocity` 为当前 S 相对基线与速度两列；匹配两参数的 S-only 是 state+历史漂移，直接 U 是 state+U_delta0。
4. 三种预测核全部报告：linear 使用 Δ；cap 使用 min(Δ,15)；decay 使用 `15*(1−exp(−Δ/15))/(1−exp(−1))`。三者在校准时长15分钟一致，decay 的上界约23.73分钟；它是有限速度修正先验，不是已经估计出真实生物学衰减常数。

## 对比与候选

固定2估计器×2聚合×2中心化×2模型×3时间核，48个速度臂；另有 identity、未拟合历史漂移、S-only、两参数 S-only、U_delta0、两参数 S+U、new_delta0 各对应时间核的对照，共67臂。全部结果落盘，不按结果改主候选。

v2 主要候选预先固定为 `pooled_shrink__pool__baseline0__state_velocity__decay`，不是从67臂中选择事后赢家。看它两个时间段是否均优于 identity，且平均 MSE 是否低于同 decay 核的 `state_history` 与 `state_U`。该规则只描述本探索网格的表现，不转为确认性统计检验。

仍是0分钟拟合源速率，15→30唯一读出训练段；30→60预测冻结后才把60作为下一源，不用120训练。已有同系列测试不再称独立留出。原始 v1 文件不改、不重算。

测试群体 γ 正值/高计数一致性、未观测 U 基因的先验标记、基线中心化归零、非负速度读出、时间核的校准一致性/有界性，以及完整滚动链。若候选仍不胜强对照，按实际数字报告，不靠继续放大网络改判。
