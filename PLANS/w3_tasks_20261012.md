## W3-2 功效对照补充

在 `w2_leadlag_power.py` 基础上新增参数，不改原逻辑。

1. **细 λ**：λ ∈ {0, 0.005, 0.01, 0.02, 0.03, 0.05}，R=50。
2. **稀疏注入**：只在随机选出的比例为 f 的基因上注入，f ∈ {0.02, 0.05, 0.2}；其余设置不变。每个 f 下 λ ∈ {0.05, 0.1, 0.2, 0.3}，R=50。每次重复重新抽基因。
3. **模块内注入**：只在 stress-like 模块的基因上注入，检验只看该模块。
4. 对每种设置报告检出率曲线和 MDE（检出率 ≥ 80% 的最小 λ），并换算成 ICC_inj 和克隆层相关。

**判读参考**：如果 f=0.05 时 MDE 对应的克隆层相关 ≤ 0.3，就可以说"即使信号只在 5% 的基因上、中等强度，也能测出来"。

**输出**：`outputs/w3_2_power_sparse.json`，以及 `docs/w3_power_sparse.png`（每个 f 一条线）。

## W3-4 官方 GFG 在 MouseBrain 上复现"不读 U"

**目的**："GFG 不读 U"涉及一篇已发表的方法。写进论文之前，必须用**原作者的代码和数据**、在**原论文的数据集**上复现。

**步骤**：

1. 使用 `/data/yuchang/GFG/` 下的原始代码（`model/` 目录）和原论文的 MouseBrain 数据，**不要用本项目改写的 `src/veloroute/gfg.py`**。
2. **回归检查**：先复现 MouseBrain 上的 Graph CBDir。对照值用修正版 GFG 自己的结果：seed0 为 0.750，seed 0–4 平均 0.620（来源：`GFG_velocity_foundation_mousebrain_v1/EXPERIMENT_SUMMARY_CN.md`）；论文报告值 0.657 一并列出。seed0 差距超过 0.05 就停止汇报，先查数据和预处理。
   - **注意输入**：原版 GFG 训练和推理用的都是 scVelo moments（`Mu`/`Ms`，S 空间 20 近邻平均），不是原始 U/S。复现时必须保持这一点。U 的变体要**先作用在原始 U 上，再重新计算 moments**，这样才能看出 moments 本身对 U 扰动的抹平作用。另外报告一组"直接改 Mu"的变体作对照。
3. 在同一模型上做三个变体：
   - U 置零；
   - 同一细胞类型内随机打乱 U（深度匹配：按受体细胞的 U 总量缩放）；
   - 全局打乱 U（深度匹配）。

   每个变体报告：GFG 速度和原速度的 cos 中位数、模长比、CBDir 的变化。
4. 参照：同样的变体下 v_kin（u−γs）的 cos 变化。
5. 如果原论文有其他数据集的 checkpoint（如 pancreas），时间允许也做一遍。

**判读**：
- U 置零后 cos 仍 ≥ 0.95 且 CBDir 基本不变 → "GFG 不读 U"在原设置下成立，可写进论文；
- cos 明显下降 → 不读 U 只是我们迁移使用（MouseBrain 权重用在人类数据上）造成的，论文里只能说"迁移场景下不读 U"。

**输出**：`outputs/w3_4_gfg_official_mousebrain.json`。

## W3-5 PerturbSci-Kinetics：数据获取与第一步信度

**背景**：Xu 等，Nature Biotechnology（2024），PerturbSci-Kinetics。HEK293-idCas9 细胞，228 个基因、699 条 sgRNA，约 9.8 万个细胞。实验末端用 200 µM 4sU 标记 2 小时；每个细胞同时有新生 RNA 和全转录组两个计数矩阵。

新旧 RNA 相当于"同一个细胞的过去和刚刚"，是唯一能在细胞内部提供短时配对的数据，也是"实测速度"版本的命题。

**步骤**：

1. 从论文的 Data availability 找 GEO 编号和处理后文件的格式：新生/全转录组矩阵、sgRNA 分配表、细胞元数据。记录文件清单和大小。**先下载处理后的矩阵，不下载原始 FASTQ。**
2. 基本统计：每个细胞新生 RNA UMI 的中位数、新生占比的中位数、每个扰动的细胞数。
3. 定义每个扰动 c 的 pseudobulk 量（参照为非靶向对照）：
   - ΔT_c：全转录组变化；
   - ΔN_c：新生 RNA 变化（反映合成速率的变化）；
   - ΔO_c：旧 RNA 变化（全转录组减新生）。
4. **信度**：细胞层三路 count-split，第 C 份挑响应基因（每个扰动 |ΔT| 最大的 200 个），A、B 两份算跨基因相关并做 Spearman–Brown。分别报告 ΔT、ΔN、ΔO 的信度中位数，全部基因和响应基因各一遍。
5. **ΔT 之外的独立成分**：η_c = ΔN − b·ΔT，b 用 IV 估计（同 W2 的 T3），报告 η 的信度。

**判读**（决定这条线下周是否继续）：

| 结果 | 决定 |
|---|---|
| 响应基因上 ΔN 信度 ≥ 0.5，且 η 信度 ≥ 0.3 | 继续：下周做"ΔN 作辅助监督预测未见扰动" |
| ΔN 信度 ≥ 0.5，η 信度 < 0.3 | 新生 RNA 可靠但和 ΔT 冗余，作为分析论文里的一个数据点 |
| ΔN 信度 < 0.3 | 关闭，作为第四个阴性数据集写进论文 |

对比参考：RENGE 内含子 ΔU 的信度是 0.061，ΔS 是 0.605。

**输出**：`outputs/w3_5_perturbsci_reliability.json`，以及 `docs/w3_results.md` 里的一节（含数据来源、文件清单）。

## W3-6 三个缺口检验（CPU，高优先级）

原命题的阴性主要靠 T1、T3 这类不依赖模型的检验。下面三个缺口不堵上，阴性就不完整。三项都复用 `w2_leadlag_power.py` 和 `w2_deltaU_reliability.py` 的数据加载与 count-split（这两个脚本已通过回归检查）。

### W3-6a 多基因低维 κ（MeRLin）

**问题**：T1 是逐基因算偏相关再平均。κ 每个基因的克隆层信度只有 0.01，但跨基因可能存在一个可靠的共同方向（比如一条通路整体偏离稳态），逐基因检验看不出来。

**脚本**：`scripts/phase0/w3_6a_kappa_cca.py`

1. 沿用 T1.4 的三路 count-split：K_A1、K_A2 是克隆 × 基因的 κ 矩阵（两份独立数据），S0 用 B 份。
2. 把 313 个克隆随机分成训练 2/3、测试 1/3，重复 20 次。
3. 在训练克隆上，对 K_A1 和 K_A2 做带岭正则的 CCA（先各自做 PCA 到 50 维；岭参数在训练克隆内做 5 折交叉验证选择）。
4. 在测试克隆上计算前 5 个典型相关（即低维成分的跨半信度）。
5. 零分布：打乱 K_A2 的克隆行，500 次。
6. 同样流程对 ε_S 做一遍，作为参照。
7. **如果 κ 的第一典型成分在测试克隆上显著**：把这个方向固定下来（只用训练克隆学），在测试克隆上做超前-滞后：偏相关(Day21 S 的对应方向, κ 成分 | S0_B)，零分布只打乱 Day21。

**判读**：κ 第一典型相关在测试克隆上不显著 → 缺口 1 关闭；显著但超前-滞后不显著 → κ 有可靠结构但与命运无关；两者都显著 → **重要，立即汇报**。

### W3-6b 离散命运标签（MeRLin）

**问题**：T1 预测的是 Day21 的连续表达，没有直接预测克隆的命运类别构成。

**脚本**：`scripts/phase0/w3_6b_fate_composition.py`

1. 找到 MeRLin 原论文给出的 Day21 命运分类程序（组会口径：每个细胞属于 5 类之一），复现 Day21 细胞的命运标签。**找不到或无法复现就停止此项并汇报**，不要自己发明分类。
2. 每个共享克隆算 Day21 命运构成（5 类比例）；只用 Day21 细胞数 ≥ 3 的克隆。
3. 预测模型：多项逻辑回归（或对比例做岭回归），输入分别为
   - (i) S0_B 的克隆均值（PCA 20 维）；
   - (ii) S0_B + κ_A；
   - (iii) S0_B + ε_S,A（正对照）。
4. 按克隆做 10 折交叉验证，指标为交叉熵（或比例的 MSE）。增量 = (i) − (ii)。
5. 零分布：打乱 Day21 克隆的命运构成与 Day0 克隆的对应关系，500 次。

**判读**：(ii) 相对 (i) 的增量不显著 → 缺口 2 关闭；(iii) 也不显著时要注明"命运类别本身从 Day0 难以预测"。

### W3-6c 短时群体层面 ΔU（RENGE，最可能出正结果的一项）

**问题**：W2 的 T3 里，day4 的 ΔU 预测 day5 的 ΔS，在控制 day4 的 ΔS 后 p=0.0005。但控制项只用半份数据，本身有噪声，ΔU 可能只是在"弥补控制不完全"。需要校正测量误差后再看。

**脚本**：`scripts/phase0/w3_6c_deltaU_leadlag_iv.py`

1. 每个条件 day4 的细胞三路 count-split（A、B、C）。ΔU4 用 A；ΔS4 用 B 和 C。day5 的 ΔS5 用全部计数。
2. **主检验（测量误差校正）**：每个条件跨基因，用两阶段最小二乘。第一阶段用 ΔS4_C 作为 ΔS4_B 的工具变量；第二阶段 ΔS5 ~ ΔS4_B(IV) + ΔU4_A。报告 ΔU4_A 的系数，对条件取平均。
3. **自检**：把 ΔU4_A 换成 ΔS4_A 重跑。校正正确时这一项应接近 0（第三次测量 ΔS4 不该有增量）。**如果它仍然明显大于 0，说明校正失败，停止并汇报**，不要解读 ΔU 的结果。
4. 零分布：只打乱 day5 的条件配对（不允许配回自己），2000 次。
5. 分别报告全部 2000 个基因、以及每个条件 |ΔS4| 最大的 200 个基因（用一份不参与检验的数据挑选，或者在 C 份里挑后从控制项中剔除 C 份）。
6. 再做一个更简单的版本互相印证：偏相关(ΔS5, ΔU4_A | ΔS4_B, ΔS4_C)，同时控制两份独立测量。

**判读**：

| 结果 | 含义 |
|---|---|
| 自检≈0 且 ΔU 系数显著为正 | **短时群体层面 U 领先 S 成立**，写进论文正面结果，立即汇报 |
| 自检≈0 且 ΔU 不显著 | T3 的 p=0.0005 是测量误差造成的，缺口 3 关闭 |
| 自检明显 > 0 | 校正方法有问题，停止 |

## W3-7 GFG 公平重训（1 GPU，高优先级）

**背景**（agent 必读）：VeloPerturb 至今用的 GFG 是修正版 GFG 在 **MouseBrain（3,365 个小鼠细胞）** 上训练的 seed0 权重（`/data/yuchang/GFG/results/mousebrain_graphbatch_directed_v1_seed0/final.pth`），直接迁移到人类数据上。而且原版 GFG 训练时输入的是 **moments（Mu/Ms）**，VeloPerturb 喂的却是**未平滑**的归一化 U/S。这对 GFG 不公平，以下两项补上公平对照。

### W3-7a R1：原版 GFG 在目标数据上重训

1. 用修正版 GFG 的原始代码（`/data/yuchang/GFG_graphbatch_directed_v1`，若不存在则用 `/data/yuchang/GFG/`），**原始预处理和全部原始损失与超参数**（moments、ODE、平滑、对齐、VQ），不做任何修改。
2. 分别在以下数据上训练，seed 0/1/2：

## W3-8 GFG v2 完整版（导师已批准，W3-7 之后开始，约 1 周）

**目标**：做出一个"既是好的速度模型、又真正读 U"的 GFG，然后用同一套下游检验它。设计按导师 10/1 的意见，并修正 W2 发现的不可识别问题。

**新文件**：`scripts/phase0/w3_8_gfg_v2_full.py`（可以 import `src/veloroute/gfg.py` 的组件，但不改 `src/`）。可以复用 `GFG_velocity_foundation_mousebrain_v1/gfg3_model.py` 的 ISAB 塔和余弦 VQ。

### 架构

| 部分 | 设计 |
|---|---|
| Token | 每个基因两个 token：U-token 和 S-token。每个 token = 数值嵌入（标准化后的计数经 MLP）+ **基因身份嵌入**（可学习，按基因词表）+ **类型嵌入**（U 或 S） |
| 状态流 | **只吃 S-token**，经 ISAB 塔、VQ（可开关），得到 z_s |
| 速度流 | **吃 U-token 和 S-token**，经 ISAB 塔、VQ（可开关），得到 z_v |
| 解码与速度 | 保留 GFG 的身份：解码器 g(z_s) 重构 (û, ŝ)；速度 v = J_g(z_s)·z_v（JVP） |
| 动力学约束 | 基因共享速率 β_g、γ_g（不再逐细胞求解）。**β_g 固定为 1**（消除尺度冗余）；γ_g 用对数参数化，加先验锚定到数据稳态估计（`fit_gamma_tail`）。损失 ‖v_s − (u − γ_g s)‖²，按 1/(1+s) 加权，权重从 0 线性升到目标值 |
| 重构 | 原始计数的负二项似然（基因级离散度） |
| 图损失 | 删除有向对齐；无向平滑权重降到原版的 1/10 或关闭（作为消融） |
| 输入平滑 | 消融：原始计数 / 5 近邻 moments / 20 近邻 moments |

W2 已经发现：JVP 加上**自由**的 β、γ 时动力学损失不可识别（模型 γ/β=1.34，数据 0.008）。所以 β 固定、γ 锚定是必须的，不能放开。

### 训练与选型

1. 先在 MouseBrain 上训练（同原版 GFG 的数据和预处理入口）。**这是保证它仍是一个好速度模型的门槛**：Graph CBDir ≥ 0.5（修正版 GFG 5 seed 平均 0.620）。
2. 再在 RENGE 训练折、MeRLin Day0 A 半上训练。
3. 消融小网格：输入平滑 {0, 5, 20} × VQ {开, 关} × 平滑损失 {关, 1/10}，seed 0。
4. **选型只看以下验收指标，不看任何下游结果**（防止对下游调参）：
   - Q1-a：V4 全局打乱 U（深度匹配）后速度 cos ≤ 0.9；
   - Q1-b：U 置零后 cos ≤ 0.9；
   - Q1-c：cos(v, v_kin) > cos(v, 均值平移)；
   - Q1-d：count-split 两半训练出的速度方向 cos ≥ 0.8；
   - MouseBrain Graph CBDir ≥ 0.5。

   选出的配置用 seed 0/1/2 重训。

### 下游（选型冻结后才跑）

- RENGE：三臂端点比较（static / v2 / V3 真局部打乱），留出 TF；条件 bootstrap。
- MeRLin：W3-1 的 count-split 超前-滞后。
- 若 W3-6a 或 W3-6c 有正结果，用 v2 速度在对应检验上重跑。

**输出**：`outputs/w3_8_gfg_v2_full_*.json`；文档 `docs/w3_8_gfg_v2_full.md`，含架构图、消融表、选型依据、下游结果。
