## 1. 要检验的科学假设

记扰动条件为 c，生物学时间为 t，预测跨度为 Δ。数据是非配对快照：同一条件在 t 和 t+Δ 各测一次，不是同一批细胞。

| 编号 | 假设 | 类型 |
|---|---|---|
| **CF-H1** | 在相同 CellFlow 基座、相同条件信息下，加入由时间 t 源细胞 U、S 计算的**群体动力学 token**，能降低 t+Δ 预测分布与真实分布的能量距离 | 主假设 |
| CF-H2 | 该增益高于"维度相同、只用 S 计算的群体摘要 token"，即增益不是"多一个 token 的容量"带来的 | 主假设的必要条件 |
| CF-H3 | 该增益高于"同一时间点内跨条件打乱的动力学 token"，即增益依赖 token 与条件的正确对应 | 主假设的必要条件 |
| CF-H4 | 增益主要体现在群体内各响应模式的比例上，而不是均值 | 机制，次要 |
| CF-H5 | 逐细胞动力学（每个源细胞携带自身动力学标签）相对群体 token 没有稳定的额外增益 | 机制，次要；对应"群体层面可识别" |

H1 成立须同时满足 H2、H3（具体判据在 W15 预注册里写，不在本文件定）。

**不检验、也不允许宣称**：逐细胞轨迹或命运。CellFlow 用小批量最优传输配对源和目标细胞，这是一个建模假设（最小作用量），不是观测；非配对数据下逐细胞对应不可识别（N1）。所以只报告分布层面的指标，不解释单个细胞的路径。

## 2. 时间：两个"时间"必须严格分开

### 2.1 CellFlow 里已有的时间不是生物学时间

CellFlow 的速度场 v_θ(x, τ | 条件) 里的 τ ∈ [0, 1] 是**流匹配的插值时间**：τ=0 是源分布，τ=1 是目标分布。`ConditionalVelocityField` 的 `time_encoder` 编码的就是 τ。**它和生物学时间（小时）没有关系，不得复用来表示 t 或 Δ。**原生 CellFlow 不支持生物学时间，需要我们显式加入。

### 2.2 生物学时间放在两个位置

**位置一：作为条件协变量（必须）**
- 起点时间 t：表示细胞所处的阶段。编码为 log(1 + t / 1h) 的傅里叶特征（4 个频率，sin/cos），作为一个不与扰动 token 池化的协变量（`covariates_not_pooled` 或等价机制）。
- 跨度 Δ：编码方式同上，作为另一个协变量。
- 二者都是**源侧已知量**，不含目标信息。

**位置二：作为积分终点（只在 Δ 超出训练范围时使用）**
- 训练集中出现过的 Δ：从 τ=0 积分到 τ=1，Δ 只通过协变量进入。
- 训练集中没出现过的 Δ（sci-FATE2：用日级转移训练、在 r4 的 5 小时窗口上测试）：仍以训练时的 Δ_train=24h 作条件，从 τ=0 积分到 **τ_end = h(Δ) / h(24h)**，其中 h 是已冻结的 decay 时间核：h(t) = 24·(1 − e^(−t/24)) / (1 − e^(−1))。
- **数学依据**：线性插值路径的条件流匹配，在小批量 OT 配对下，其边缘路径 p_τ 近似源到目标 OT 映射的位移插值（McCann 插值）。在"群体沿测地线匀速移动、速度按 h 的导数缩放"的假设下，跨度 Δ 的预测对应插值比例 h(Δ)/h(24)。这和小模型使用的时间核完全一致，两条线的时间处理因此可比。
- 这是一个**假设**，必须报告敏感性：同时报告 τ_end = Δ/24（线性时间）的结果；主结果用 h 核，在冻结前写定。
- 不允许根据 r4 分数在两种 τ_end 之间挑选。

### 2.3 动力学 token 的时间戳

动力学 token **只在源时间 t 上计算**，只用时间 t 的源细胞；t+Δ 的任何数据（细胞、计数、标准化统计）都不得进入 token。实现上，token 计算函数的输入只能是源细胞的索引集，单元测试要验证这一点（第 6 节第 1 条）。

## 3. 插件加在哪里

### 3.1 状态空间（所有臂相同）

细胞状态 x = 冻结 PCA-50 坐标：只用训练源细胞拟合 HVG2000、文库归一化、log1p、PCA，和小模型同一规则。CellFlow 在这个 50 维空间里做流匹配（不使用 CellFlow 自带的编码器做降维，保证两条线状态空间一致）。

### 3.2 主插件：群体动力学 token（位置：条件编码器）

对条件 c 在时间 t 的源群体：

1. 合并计数：把该群体全部源细胞的 raw U、S 计数相加，用**全基因 S 文库深度**归一化（U 用同一个 S 因子），得到 ū、s̄（与 W4 `vel_pool` 相同）；
2. 动力学向量：k_raw = W · [(ū − γ ⊙ s̄) / (1 + s̄)]，W 为冻结 PCA 载荷，γ 为冻结的每基因稳态比（仅训练源拟合）；
3. 参考场：减去参考 k_ref（sci-FATE2：该重复最早时间点的同一构造，与小模型一致；扰动数据：同一时间点非靶向对照群体的同一构造；没有对照时用 0，写入第 9 节）；
   - 已知后果：sci-FATE2 中从最早时间点出发的窗口（r4 的 05→10h、各重复的 D3→4）token 按定义为零，插件在这些窗口不提供信息。为与小模型可比，主设计保留这一定义；结果中把这些窗口单独标出，不剔除；
4. 标准化：用训练群体的 token 拟合均值和标准差，冻结；
5. 输入 CellFlow：作为一个独立的、不与扰动 token 池化的协变量，经一个固定结构的小 MLP（50→64→条件维度，SiLU）映射后与其他条件拼接。

**为什么放在条件编码器，而不是状态里**：
- 流匹配把源状态 x 搬到目标状态 x。如果把动力学并进状态向量，目标细胞也必须有"动力学坐标"，模型就要连目标的 U 一起预测，偏离了任务；
- 放在条件里，速度场变成 v_θ(x, τ | e_c, t, Δ, k_c,t)：同一个源分布，在不同群体动力学下流向不同的目标分布。这正是"动力学决定群体去向和模式配比"的数学表达，也和小模型的发现（群体平均路由保留大部分增益）一致。

### 3.3 次要插件：逐细胞动力学标签（位置：每个源粒子的条件）

- 每个源细胞 i 携带自身的局部动力学 κ_i（S-PCA 64 近邻池化后按 3.2 的同一公式计算），在整条积分路径上固定不变；
- 速度场为 v_θ(x, τ | e_c, t, Δ, κ_i)。这是"条件随粒子固定"的流匹配：κ_i 是源粒子的属性，不是状态，目标细胞不需要 κ；
- 训练时，κ_i 跟随小批量 OT 配对中的源细胞；推理时，每个源细胞带着自己的 κ_i 积分；
- 若服务器上的 CellFlow 版本不支持逐样本条件，用包装层实现（第 5 节），不改库源码；实在做不到就只做主插件，写入第 9 节。

### 3.4 不做的事

- **不加小模型的均值锚。**小模型所有臂共享一个用到 U 的解析均值，CellFlow 线不加，因此 CellFlow 的 static 臂是真正的"只用 S"。两条线的 static 含义不同，论文里分开写，不直接比较两条线的绝对数字；
- 不用 CellFlow 自带的扰动嵌入替换现有 ESM2 嵌入（扰动数据统一用 ESM2；sci-FATE2 没有多扰动，e_c 为常数）。

## 4. 对照臂

所有臂使用**完全相同的网络结构**：群体 token 输入和逐细胞标签输入两个位置在每个臂里都存在，不用的位置输入常数零。不同的只是输入值，这样参数量严格相等。

| 臂 | 群体 token 输入 | 检验什么 |
|---|---|---|
| `cf_static` | 常数零向量 | 基线（只用 S 和条件） |
| **`cf_kin`** | 真实群体动力学 token（3.2） | **主臂** |
| `cf_Ssum` | 同群体的 S 摘要：W·log1p(s̄) 减参考、同样标准化，维度相同 | CF-H2：排除"多一个 token 的容量" |
| `cf_kin_shuf` | 同一生物学时间点内，把动力学 token 在条件之间随机置换（3 个置换种子，分别训练） | CF-H3：排除"有 token 就行，不需对应" |
| `cf_directU` | W·log1p(ū) 减参考，不用 γ | 区分"U 本身"和"动力学构造" |
| `cf_kin_cell` | 逐细胞标签 κ_i（3.3），群体 token 置零 | CF-H5 |

- 每个臂 3 个训练 seed，预测按三 seed 混合评估（与小模型相同口径）。
- `cf_kin_shuf` 需要同一时间点至少 3 个条件。sci-FATE2 每个时间点只有一个群体，**不做**该臂，改为在 sci-FATE2 上只报告 `cf_kin_cell` 的源群体内打乱版本，并注明 CF-H3 只能在扰动数据上检验。

## 6. 单元测试（全部通过才能运行 CF-2）

1. **无目标泄漏**：对 t+Δ 的细胞加随机扰动，所有 token、标准化统计、源变换的哈希不变；
2. **token 只用源细胞**：token 函数的输入索引集合与源细胞集合一致；
3. **两个时间分开**：改变生物学 t 或 Δ 只通过条件协变量影响速度场；τ 的编码路径与生物学时间路径在计算图中没有共享输入；
4. **τ_end 正确**：τ_end=1 时与完整积分逐元素一致；τ_end=0 时输出等于源；τ_end=h(Δ)/h(24) 的数值与手算一致；
5. **结构相同**：六个臂的可训练参数量完全相同；`cf_static` 的 token 输入恒为零；
6. **打乱臂边缘分布不变**：`cf_kin_shuf` 的 token 集合与 `cf_kin` 相同，只是对应关系改变；
7. **合成数据**：构造"目标模式比例由一个隐藏的群体动力学变量决定"的数据，`cf_kin` 应优于 `cf_static` 与 `cf_Ssum`；零效应情形下三者无系统差异。正、零各 20 次重复，报告全部数值；不得把单次超过阈值当作统计检出。

## 7. 评估指标

- **主指标**：预测分布与真实分布的能量距离，固定 512 源 / 512 目标子样本（seed 0，少于 512 时用全部细胞、不放回、报告实际数量），三 seed 混合；
- **均值误差**：预测均值与真实均值在 PCA-50 上的平方误差；
- **模式比例误差**（CF-H4）：只用训练目标细胞拟合 k-means（k=8）并冻结；把预测细胞和真实细胞分别分配到簇，计算两组簇比例的总变差距离；
- 全部时间窗、全部臂、全部 seed 原样报告，不挑窗口。

## 8. 两条线的结论规则（写入 W15 预注册前由 Rinck 确认）

| 结果 | 写法 |
|---|---|
| 两条线都有增益 | 机制成立，且能迁移到强生成模型 |
| 小模型有，CellFlow 没有 | 强模型已从 S 中学到这部分信息；动力学的价值主要在可解释性与小模型上 |
| CellFlow 有，小模型没有 | 增益可能来自 CellFlow 与插件的交互；机制解释降级 |
| 都没有 | 走边界分析路线 |

主结论以 CellFlow 线为准。
