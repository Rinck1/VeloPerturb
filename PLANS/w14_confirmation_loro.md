## 0. 为什么做这件事

W5–W13 的全部 sci-FATE2 阳性结果都在 r4 一条小时级序列上评估，而 K、步数、配方、ODE 步长均参考过 r4 分数选定。r4 因此只能算**开发集**。

本实验回答一个问题：

> 用已定型的配方，在**从未被评估过**的生物学重复上，真实动力学路由是否仍然优于 static 与打乱动力学？

r1–r3 一直只用于训练，从未作为测试目标评分，是 sci-FATE2 内部唯一未被评估过的数据。

本实验**不**用于继续选模型。无论结果如何，W5–W13 的结论不回改，只决定后续方向（见第 7 节）。

## 4. 对照臂

所有臂共享同一个冻结均值分支（每折重新拟合的同一流程）、相同的专家结构、训练步数、batch 与采样预算。只改变**局部路由的输入**。

| 臂 | 路由输入 | 身份 |
|---|---|---|
| `static` | 源 S 状态 | 主对照一 |
| `real` | 源 S 状态 + 真实局部动力学（邻域池化的解析 U−γS 投影） | **主臂** |
| `shuffled_v` | 源 S 状态 + 源群体内打乱的局部动力学；打乱用 5 个独立置换种子 | 主对照二 |
| `direct_U` | 源 S 状态 + 邻域池化的 W·log1p(u_pool)（不估 γ，不减 γS），与 `real` 同维度 | 次要对照 |
| `nonlinear_SU` | 源 S 状态 + 邻域池化的 [W·log1p(s_pool), W·log1p(u_pool)] 经一个与 `real` 动力学输入层同参数量的 MLP | 次要对照 |

- 主臂与 `static`、`direct_U`、`nonlinear_SU` 各 3 个训练 seed（0/1/2）。
- `shuffled_v`：3 个训练 seed × 5 个置换种子 = 15 次训练，形成打乱分布。
- 参数量：`direct_U`、`nonlinear_SU` 与 `real` 的差异写入汇报；若无法精确匹配，差异须在 ±5% 以内。

## 5. 单元测试（全部通过才能冻结）

1. 留出重复的任何数据都不进入 HVG/PCA/γ/均值分支/路由的拟合：在留出重复上加随机扰动，所有拟合产物哈希不变。
2. 均值锚恒等式：所有臂预测混合的群体均值等于冻结均值分支输出（容差 1e−5），且对路由参数的导数为 0。
3. `shuffled_v` 只在同一源群体内置换，边缘分布与 `real` 完全一致。
4. `direct_U`、`nonlinear_SU` 不读取 γ；`static` 不读取任何 U。
5. 评估入口在预测清单不完整或哈希不符时拒绝运行。
6. 合成数据端到端：植入"动力学决定模式比例"的数据上，`real` 优于 `static`；植入零效应时两者无系统差异（各至少 20 次重复，报告检出率与误报率）。

## 6. 指标与判据（冻结后不改）

**主指标**：留出重复每个转移上的预测混合**能量距离**，固定 512 源 / 512 目标细胞子样本，子样本种子固定为 0，所有臂共用；三个训练 seed 的预测混合等权合并后计算。

**相对改善**：g = (E_ref − E_real) / E_ref。

**汇总**：先在每折内对 5 个转移等权平均，再对 3 折等权平均，得到 Ḡ。

**主判据（两条都满足才算确认）**：

| 编号 | 内容 |
|---|---|
| P1 | `real` 对 `static`：Ḡ > 0，且 3 折中至少 2 折的折内平均 > 0 |
| P2 | `real` 对 `shuffled_v`：`real` 的平均能量距离低于 5 个置换种子中**全部**的平均能量距离（即排在打乱分布之外），且 3 折中至少 2 折满足 Ḡ > 0 |

**结果分级**：

| 结果 | 结论写法 |
|---|---|
| P1、P2 都满足 | 在未评估过的重复上确认：真实动力学路由优于 static 与打乱动力学 |
| 只满足其一 | 部分确认，写明哪一条未过 |
| 都不满足 | 未确认；r4 上的增益可能主要来自选择偏差，按第 7 节处理 |

**次要报告（描述性，不进入判据）**：
- `real` 对 `direct_U`、对 `nonlinear_SU` 的 Ḡ 与逐折数值；
- 每个转移、每折、每 seed 的全部数值，不挑选；
- 冻结干预：对主臂把逐细胞路由换成群体平均，报告保留的改善比例（对应 W12 的 97.8%）；
- 均值 MSE（均值分支本身对 S-only 均值读出的改善）；
- 细胞层面分层 bootstrap（1,000 次）给出每个转移的区间，用于描述，不作显著性判据。3 折、15 个转移不是独立生物学重复，不做显著性检验。
